## 1. 重要な訂正: Oceanic は「初期から工場なし」ではなく「喪失後の再建」
P29-011 は Oceanic を「MilitaryFactory がなく、MS 備蓄 12、師団 0」と記述したが、**初期データの Oceanic は MilitaryFactory lv1(州 8 = 首都)を持つ**。全 6 国が初期に MilitaryFactory を持つ:
| 国 | 初期 MilitaryFactory(州) | Iron 鉱床の州 |
|---|---|---|
| Arcadia | lv2(州 0・12) | 州 0 |
| Elfin | lv1(州 18) | 州 16 |
| Dwarf | lv2(州 6) | 州 5 |
| Oceanic | lv1(州 8) | **州 8** |
| Passguard | lv2(州 10・13) | 州 13 |
| Ferrowyn | lv1(州 26) | 州 21 |
各国の初期の Iron/Coal 鉱床はちょうど 1 州で、Oceanic はそれが MilitaryFactory と同じ首都 8 にある。州 8 は 1801/06/01 の降伏(Dwarf 対 Oceanic)で失われ、**MilitaryFactory・Iron/Coal 鉱床・初期師団(撃破)を同時に失った**。以降、Oceanic の所有 5 州に採掘可能な資源はない。したがって標準データには「初期から工場なし」の国は存在せず、立ち上げ(§4-A)は仮想のケース(データ変更時)であり、Oceanic は「喪失後再建(§4-B)」の事例である。

## 2. Oceanic が復帰できない条件(実測とコード上の根拠)
`tests/p30_001_diag_001_oceanic_rebuild_test.rs`(標準全 AI シナリオの月次記録)。
### 2-1. 現在の軍備目標と、師団を持とうとする条件
- 目標師団数 = `calculate_ai_target_divisions(人口由来の上限, 1 個の必要兵力 10,000)`(`src/military/ai.rs`)。Oceanic: 上限 17.5 万〜20.7 万 → **目標 8〜10 個**(1801/06 以降)。初期は 19 個。
- 人的資源は制約でない(`available_manpower` 15 万〜20 万 ≫ 必要 10,000+予備)。国庫も 4,600〜12,000 で建設費(1,200)を賄える。
- 師団 0 < 目標なので、**毎月、AI は募兵を試みる**(評価は実際に走る)。

### 2-2. 募兵を止めている具体的な判定
`decide_and_recruit_for_country`(`src/military/ai.rs`)の補給ゲート(`evaluate_recruitment_supply_gate`、`src/military/recruitment_supply_gate.rs`)で `SkippedSupplyShortage`。
- 停止判定は「備蓄日数」ではなく**橋渡し不足**: `compute_bridge_deficit_units(現在需要 + 追加 1 個の需要, 月, 日, 備蓄)` > 0。追加する師団 1 個の需要 1.0/日 × 次の月次生産までの日数(30〜31)= **約 31 の MS 備蓄**が募兵の前提で、Oceanic の備蓄は **12.3 で一定**(不足 17.7〜18.7 MS)。
- **古いフラグ値ではなく実評価**: 記録した 1801/06 以降の全標本月で、フラグ(`recruitment_supply_blocked` = true)と、開放状態から評価し直した結果(true)が一致(テストで確認)。E3(能力ゲート)は最小常備戦力 2 の免除で通るため、止めているのは補給ゲートだけ。

### 2-3. MilitaryFactory が建設候補に入るか
- **平時の経路がない**。優先度 1(Farm)・2(未活用鉱床の Mine / Factory)・2.5(戦時のみ)・2.7(Railway)・2.8(B1: Mine)・3(Mine か Factory)のいずれも、平時に MilitaryFactory を選ばない。初期データの MilitaryFactory は「建設 AI が MilitaryFactory を対象にしないため必須」(`assets/data/states.ron` のコメント)として配置されている。
- **戦時の経路(優先度 2.5、`try_wartime_supply_construction`)は条件が循環する**: ①戦時のみ(`WartimeSupplyContext` は戦時の AI だけに構築)、②`所有州の実月産 < 日次需要 × 30`(需要 0 なら着工しない)。師団 0 の国は**需要が 0 なので、戦時でも着工しない**(1818/01 の戦時も確認)。
### 2-4. 循環待ちの説明(条件と呼び出し経路)
```
募兵(補給ゲート): MS 備蓄 ≥ 約 31 が必要
   └─ MS: MilitaryFactory の生産が必要(なければ備蓄は 12.3 のまま)
        └─ MilitaryFactory の建設: 平時の経路なし / 戦時の経路は「日次需要 > 実月産」が必要
             └─ 日次需要: 生存師団の需要。師団 0 なら 0
                  └─ 師団: 募兵が必要 → (最初に戻る)
```
どの段階にも「例外」はなく(免除経路は E3 の能力条件だけで、補給ゲートには及ばない)、一度師団を全て失い、備蓄が橋渡し量未満の国は、外部の変化(領有)がない限り復帰できない。
### 2-5. 建設費・予備資金・建設可能州・技術・操業可能性
- 建設費 1,200・予備資金(+月次経常支出 × 3)は国庫(4,600 以上)で満たせる。技術による建設制限は建物定義にない。
- 建設可能州: 所有 5 州に建設余地あり(州 9: Magic Harbor など)。
- **操業可能性**: MilitaryFactory の稼働率は `min(雇用率, 物流比, 入力充足率)`。Oceanic の首都州 8 の雇用率は 0.029〜0.123(人口 210 万・潜在労働力 105 万に対し、雇用 3〜13 万)。**MilitaryFactory の月産は 3〜12 MS**(稼働率 0.03〜0.12)で、1 個の月需要(約 30)に届かない。喪失前も、備蓄は 5.6〜11.3 に留まっていた(初期の MilitaryFactory 自体が、雇用率の制約で橋渡し量に届かない設計だった)。

## 3. 国内での到達可能性(段階別)
Oceanic の喪失後(1801/06 以降)を基準に分類する。
| 段階 | 分類 | 根拠 |
|---|---|---|
| 1. 必要な原料(Iron・Coal)の供給 | **資源で不可能** | 所有 5 州に採掘可能な Iron/Coal 鉱床なし(鉱床があるのは失った州 8 のみ)。交易・輸入・移送の機能は未実装。Mine を建てても産出する資源がない |
| 2. 中間財(IG)の生産 | 部分的に可能(備蓄のみ) | 喪失時の IG 備蓄 108 と Fe 142・Co 130 を Factory が IG 304 へ変換して消費し(1803 年に Fe 12・Co 0・IG 304 で凍結)、以後は原料がなく追加生産できない |
| 3. 最初の MilitaryFactory の建設・稼働 | **判断経路がない**(建設・稼働自体は可能) | 補助実験(下記): 州 9 へ 1 件建設すると 3 か月で完成・稼働(稼働率 0.18、月産 18) |
| 4. 補給備蓄の形成 | 可能(3 が実現すれば) | 補助実験で備蓄 12.3 → 30.5(橋渡し量を超える)に 3 か月で到達 |
| 5. 既存条件を満たした募兵 | 可能(4 が実現すれば) | 補助実験で補給ゲートが開き、1801/11/30 に募兵 AI が 1 個を募兵 |
- **補助実験(状態を操作。通常シナリオの再現ではない)**: 1801/08/01 に州 9 へ MilitaryFactory lv1 の建設注文を 1 件だけ入れ、以降は既存の機能だけで進めた(物資の無償生成・ゲート免除・資源追加なし)。結果: 募兵まで到達したが、**Iron が供給できず備蓄(136)が約 11 か月で尽き(1802/07)、MilitaryFactory の稼働率は 0、MS は 0 に戻り、師団 1 個が補給 0 のまま残った**。持続しない。
- したがって Oceanic は「判断経路がない」(段階 3)と「資源で不可能」(段階 1)の両方に該当し、**前者を直しても後者のため持続できない**。資源がないことを Mine の建設で解決することはできない。

## 4. 立ち上げ・喪失後再建・操業停止・備蓄待ちの区別
一つの「軍需不足」フラグにはまとめない。観測の違いで区別する。
| 区分 | 観測の定義 | 該当・既存の対応 | 今回の仕様の対象 |
|---|---|---|---|
| A 初期から軍需工場がない国 | 全州の MilitaryFactory レベル合計が 0(ゲーム開始から) | **標準データには該当なし**(全 6 国が初期に保有)。データ変更時は Oceanic と同じ経路で復帰できない | 対象(B と同じ判定で扱える) |
| B 工場・生産州を失った国 | MilitaryFactory レベル合計が 0(喪失後) | **Oceanic**。現状の復帰経路なし(§2) | **対象(主)** |
| C 工場はあるが入力不足で停止 | MilitaryFactory があり、Iron 未充足が継続(P29-009) | B1(Iron の Mine)で対応。Iron 鉱床がなければ B1 は候補なし | 対象外(既存) |
| D 供給基盤はあるが備蓄形成を待っている | 持続的な月産 ≥ 1 個の月需要、備蓄が橋渡し量未満で増加中 | 既存(待てば補給ゲートが開く) | 対象外(何もしない) |
全国家に軍需工場を持たせることは目的にしない。軍備目標(目標師団数)と国内供給の実現可能性に基づく。

## 5. 推奨する最小実装(P30-002 の仕様)
### 5-1. 結論
**国内建設で実現できる範囲**(Iron の国内供給源がある場合)と、**国内では実現できない範囲**(Oceanic 型: 供給源を全て失った国)を分ける。

### 5-2. 国内建設で実現できる場合: 「軍需基盤の再建」(優先度 2.9)
| 項目 | 仕様案 |
|---|---|
| 再建需要を認識する条件(すべて) | R1 AI 国家(プレイヤー除外)。R2 戦力が目標未達: 生存師団 + 募兵キュー < 目標師団数(既存の `calculate_ai_target_divisions`)。R3 **軍需基盤がない**: 所有州の MilitaryFactory レベル合計 = 0。R4 **持続的な MS 月産が 4 か月の履歴で確認できる**(P29-005 の履歴が窓幅 4 に達している。未集計は「再観測」として着工しない)。R5 **国内で Iron を供給できる**(下記) |
| R5: 入力財 | 所有州に discovered な Iron 鉱床があり、**Mine が稼働している(レベル > 0)か、B1/優先度 2 で建設できる状態**。IG は備蓄または Factory で賄える(Factory が稼働している、または IG 備蓄が新しい工場の 1 か月分以上)。**満たさない場合は着工せず、何も変更しない**(Oceanic はここで不発。資源がないことを Mine で解決しない) |
| 最初に候補へ追加する建物 | **MilitaryFactory lv1**。候補州は、既存の `projected_military_factory_supply_gain`(雇用率・物流比の見込み)が正で最大の州(同値は StateId 最小)。入力の月分の備蓄は既存の `wartime_supply_inputs_covered` を再利用 |
| 既存の建設優先順位との関係 | 優先度 2.8(B1)の後・3 の前の **2.9**。戦時の 2.5 が先に評価され、2.5 が着工した場合は 2.9 は評価しない。平時・戦時とも評価する。着工しない場合は優先度 3 へフォールスルー(無関係な判断を止めない) |
| 予算・予備資金 | 優先度 3 と同じ規則: 国庫 ≥ 建設費 + 月次経常支出 × 3 か月分(非有限・負は着工しない)。赤字建設を許可しない |
| 重複防止 | 建設キューに MilitaryFactory があれば着工しない(建設中の見込みを重複計上しない)。同一更新の先行注文もキューで見える。1 判断 1 件 |
| 再建判断の終了 | R2〜R5 のいずれかが偽になる(目標達成・MilitaryFactory が 1 つ以上できた・入力が満たされなくなった)。MilitaryFactory ができた後の能力不足は別の経路(B1 は Iron 律速、その他は未対応)で、2.9 は再建(レベル合計 0)だけを扱う |
| New Game・Save/Load | **新しい永続状態なし**: 判断は登録済みの状態(州の建物・鉱床・建設キュー・国庫)と P29-005 の履歴(Save 済み)から毎回再導出する。旧 Save は履歴が空のため、4 か月の再観測の後に判定する(その間は従来の判断) |
| 変更しないもの | 募兵の備蓄条件・最小常備戦力 2・窓幅 4・B1/B2・D4・70 日分・E1・初期資源/備蓄・建物基本出力。**補給ゲートの免除や MS の無償生成はしない** |

### 5-3. 受け入れ条件(次タスクのテスト)
1. 再建の fixture: MilitaryFactory なし・Iron 鉱床と稼働中の Mine あり・入力の備蓄あり・目標未達・履歴 4 か月・国庫十分 → MilitaryFactory lv1 が最大 gain の州に着工され、国庫が建設費だけ減る。
2. 不発の網羅: 目標達成済み / MilitaryFactory あり / 建設キューに MilitaryFactory あり / 履歴が未集計 / Iron の国内供給源なし(Oceanic 型: 鉱床なし)/ 入力の備蓄不足 / 予備資金不足(境界 800 相当を含む)/ 候補州なし(gain ≤ 0)/ プレイヤー国家。いずれも国庫・キューを変更しない。
3. 同一更新の重複: 同じ判断を複数回呼んでも MilitaryFactory は 1 件、キュー上限 2 を超えない。優先度 2.5 と 2.9 が同時に着工しない。
4. 従来の判断の維持: 2.9 が不発のとき、優先度 3 以降の結果が変更前と同一。
5. 実経路: 補助実験の再現(完成 → 備蓄 ≥ 橋渡し量 → 補給ゲートが開く → 募兵 AI が募兵)が、無償生成・免除なしで成立する。
6. Save/Load: 旧 Save(履歴なし)で 4 か月の再観測後に判定、新 Save で履歴・判断が一致。
7. 標準シナリオ 600 か月 + 長期 1950 年: 他国の着工が変わらないこと(R3 を満たす国だけ変わる)。Oceanic は R5 を満たさず不発であることをそのまま報告する(閾値の調整や条件の緩和をしない)。
8. 全体テスト・clippy。

### 5-4. 国内では実現できない範囲(Oceanic 型): 必要な設計判断(採用しない)
Iron/Coal 鉱床を全て失った国は、MilitaryFactory を再建しても原料が供給できず(補助実験: 約 11 か月で枯渇)、持続しない。次のいずれかを**ユーザーが判断**する必要がある。
| 案 | 内容 | 影響・未決事項 |
|---|---|---|
| (a) 交易・輸入の機能 | 資源を他国から入手する機能の新設 | 経済モデルの拡張(価格・相手国・輸送)。大きな設計 |
| (b) 資源州の獲得を戦争目標に反映 | AI の宣戦・目標選定が、軍需の資源州(Iron/Coal)の欠損を考慮する | 外交・戦争 AI の変更。標準シナリオの世界が変わる |
| (c) 資源を持たない国を許容する | 非武装のままの国を、ゲーム内の結果として許容(現状) | 仕様の明文化のみ。Oceanic は 150 年間師団 0 のまま |
| (d) 備蓄の支給(無償生成) | **採用しない**(指示により、物資の無償生成・ゲート免除は不可) | — |
推奨: まず 5-2 を実装し(Iron の供給源が残る国の再建と、データ変更時の立ち上げ)、Oceanic 型は (c) を既定とし (a)(b) は別 Phase の設計判断とする。
