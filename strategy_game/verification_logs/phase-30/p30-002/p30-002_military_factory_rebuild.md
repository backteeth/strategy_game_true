## 1. 再建需要の認識(`military_rebuild_context`)
次をすべて満たすときだけ再建候補を評価する(平時・戦時とも)。
| 条件 | 実装 |
|---|---|
| AI 国家 | 日次の国家 AI の対象(プレイヤー国家は除外) |
| 戦力が既存の軍備目標に未達 | 生存師団(兵力 > 0・撃破でない)+ 募兵キュー < `calculate_ai_target_divisions`(人口由来の上限 ÷ 1 個の必要兵力)。**現在の師団数が 0 でも、補給消費量が 0 でも、目標から認識する** |
| 所有する MilitaryFactory のレベル合計が 0 | 現在の所有状態から導出(「過去に持っていた」履歴は追加しない。初期から工場がない仮想ケースにも同じ条件が適用される) |
| P29-005 の有効な連続 4 か月の履歴 | `SupplyProductionHistory::average_units`(判断月が最後・連続・集計失敗なし)。旧 Save・New Game 直後は 4 か月の再観測まで保留 |
| MilitaryFactory が建設キューにない | 着工関数で確認(建設中・同一更新の先行注文を含めて重複しない) |
| 国内供給の見込み | §2 |
補給備蓄が募兵条件未満であることは、再建の禁止条件にしない。

## 2. 国内供給の定義(未決事項の確定)
「鉱床がある」「備蓄が残っている」「継続して供給できる」を区別する。**稼働している供給源の実績**だけを供給として認める。
| 項目 | 定義 |
|---|---|
| Iron の国内供給源 | 所有州の discovered な Iron 鉱床の基本出力 × その州の **Mine レベル** × Mine の**記録済みの稼働率**(月次生産の Mine 分岐と同じ式)の合計(Iron/月)。鉱床があるだけ・Mine が未稼働・稼働率が未記録(未集計)・備蓄が残っているだけは供給源としない |
| 採掘設備・稼働見込みの確認 | Mine レベル > 0 かつ稼働率の記録が正であること。記録がない(新設直後)は未集計として保留 |
| IG の国内供給 | 所有州の Factory の IG 出力 × レベル × 記録済みの稼働率(実績の月間 IG 産出)。Factory が稼働している実績は、その Iron・Coal の入力が国内で継続供給されている観測でもある(IG 備蓄だけは供給源としない) |
| IG 製造の原料・制約 | Factory の入力(Iron・Coal)の制約は、Factory の稼働実績に既に反映されている(別に Coal の鉱床を判定しない) |
| 必要量 | MilitaryFactory の基本入力(Iron 30・IG 15)× **見込みの稼働率**(候補州の増産見込み ÷ MilitarySupplies の基本出力)。Iron・IG 以外の入力を要求する定義は、判断できないため保留 |
| 判定 | 供給(実績)≥ 必要量(Iron・IG の両方)。満たさなければ着工せず、何も変更しない |
| 未集計・情報不足 | 保留(不発)。0 や無限大として扱わない |
- 有限の初期備蓄だけでは供給源にならない(P30-001 の補助実験のように、残存 Iron を使い切って止まるだけの再建は許可しない)。
- 限界: 国内の Factory などとの Iron の競合は、必要量との比較では考慮しない(必要条件であり十分条件ではない。D4 の配分と B1 が既存の競合を扱う)。

## 3. 建設判断への統合
| 項目 | 内容 |
|---|---|
| 優先度 | **2.9**: 優先度 2.7(Railway)・2.8(B1)の後、通常判断(3)の前。戦時の 2.5 が着工した場合は 2.9 を評価しない。不発時は優先度 3 へフォールスルー(従来の判断は変わらない。テストで確認) |
| 建設するもの | MilitaryFactory **lv1 を 1 件**(目標レベル 1) |
| 建設先 | 所有かつ支配する陸上州のうち、既存の増産見込み(`projected_military_factory_supply_gain`)が**正で最大**の州(同値は StateId 最小)。MilitaryFactory のない州だけ。見込み 0 以下の州は選ばない |
| 予算 | 優先度 3 と同じ予備資金規則: 国庫 ≥ 建設費 + 月次経常支出 × 3 か月分(`peacetime_reserve_satisfied`。境界を含む)。赤字建設を許可しない |
| 重複防止 | 建設キューに MilitaryFactory があれば着工しない(同一更新の先行注文もキューで見える)。キュー上限 2 は既存の判断で守られる |
| 終了 | 目標達成・MilitaryFactory の完成(レベル合計 > 0)・供給条件の喪失で、文脈が作られず追加発注しない。既存注文の取消・完成後の連続増設は追加していない |
| 判断理由 | 既存の `PeacetimeDevelopment` を再利用(Save V1 の値域を広げない) |
| 「正の産出」と「師団の持続」 | 見込みが正の州だけ選ぶ。1 個の月需要(約 30.4)に満たない見込みは、診断関数 `military_rebuild_gain_units` で別に評価できる(テスト `positive_gain_is_distinct_from_sustaining_a_division`) |

## 4. 保存互換性
**新しい永続状態なし**。判断は登録済みの状態(所有州の建物・鉱床・稼働率の記録・建設キュー・国庫・師団)と P29-005 の生産履歴(Save 済み)から毎回再導出する。
- New Game: 履歴が空 → 4 か月の再観測まで保留(前セッションの判断は残らない)。
- Load: 同じ状態なら同じ判断(e2e で、同じ保存点から着工日が一致)。
- 旧 Save(履歴なし): 履歴が 4 か月揃うまで再建需要を認識しない(e2e: ロードの 4〜5 か月後から認識)。
- プレイヤー国: 自動で建設しない(e2e)。
- 州・資源・工場を失った場合: 現在の所有状態で判断する。

## 6. 再建できた範囲と残る能力不足
- **できた範囲**: 国内に Iron・IG の継続供給源があり、MilitaryFactory を持たない(失った/ない)AI 国家は、補給備蓄・師団数にかかわらず、MilitaryFactory lv1 を建設し、完成・月産・募兵(最小常備戦力 2)まで既存の経路だけで復帰できる(fixture)。
- **残る能力不足**:
  1. 建設キュー(上限 2)が低優先の Factory 注文で埋まると、再建の着工が数か月遅れる(fixture で 6 か月)。既存注文の取消は追加していない。
  2. MilitaryFactory lv1 の月産が 1 個の月需要(約 30.4)や最小常備戦力 2(約 61)に満たない州では、着工後も師団を持続できない(低雇用の州。完成後の連続増設の経路は未実装)。
  3. 再建は MilitaryFactory のレベル合計が 0 の場合だけ。レベルがあっても能力不足の国は別の課題(Iron 律速は B1)。
  4. Factory との Iron の競合は必要条件の判定に含めていない。
- **Oceanic 型に残る設計判断**(採用していない): (a) 交易・輸入の新設、(b) 資源州の獲得を戦争目標へ反映、(c) 資源を持たない国を許容(現状の既定)。
- Phase 29 の残課題(戦力拮抗の長期戦争・70 日分の備蓄形成の時間・国庫の余剰・Arcadia 型の原料不足・評価範囲の限定・Passguard の未確定事項・手動確認)は、今回扱わず引き継ぐ。
