# P32-038 (M6-e) ステート単位の実効支配・占領集計

基準コミット: be15eec。実装範囲は**集計と検証用CLIだけ**。D6(人口・生産・税の帰属、戦争点数の換算・閾値)・D7・占領進捗・補給による移動速度は決めていない。
所有・支配・交戦関係は**検証シナリオの入力**であり、正式な所有・実効支配データではない。

## 1. 集計規則(`src/world/state_control.rs`)

入力: `WorldModel` の所属(正本)、シナリオの `state_owners`(法的所有。`DivisionScenario.state_owners` として保持するようにした。`MapMilitary` には入らない)、`ProvinceControl`(実効支配)。
集計は呼ぶたびにプロヴィンスの支配から導出する。ステートに独立した支配データは持たせず、保存もしない。補給の到達要約(`state_reach`)は使っていない。

- ステートごとに、法的所有国・所属総数(分母)・国別の支配件数・支配国なしの件数。出力は `MapStateId` 昇順、国別は `CountryId` 昇順。
- 区分: `NoProvinces`(所属 0 件)/ `NoController`(所属ありで全件が支配国なし)/ `Full(国)`(全件同じ国)/ `Mixed`(複数国、一部に支配国なし、一部だけの支配)。
- ステート未所属のプロヴィンスは、どの分母にも入れない(件数だけ `unassigned()`)。
- 割合は `ShareOf { numerator: その国の支配件数, denominator: 所属総数 }`。支配国なしも分母に含む。小数にはせず分子・分母を保持(表示用に `as_f64`)。
- 法的所有国と実効支配は別の値。第三国の支配は国別の内訳に含めるが、占領には加算しない。
- 「占領」は `StateControl::occupation_by(占領国, at_war)` で、**所有国と占領国の交戦関係を述語で明示**して判定する。所有国なし・所有国自身・交戦中でない国は `None`。交戦中で支配 0 件なら `Some(0/総数)`。交戦国ごとに別々の値で、合算しない。
- 各ステートで 国別件数の合計 + 支配国なし = 所属総数(`is_consistent`)。入力順に依存しない(内部は `BTreeMap`。`CountryId` は `Ord` を持たないので `usize` をキーにして `CountryId` へ戻している)。
- 入力エラー: ステートの重複、プロヴィンスの複数ステート所属(未所属との重複も含む)、所属表にないステートへの法的所有。
