## 2. 起動と独立App

```
cargo run --bin map_economy_session                        # 既定: m4e(資源は m4d のもの)、操作国家は未選択
cargo run --bin map_economy_session -- --scenario m4d      # 明示(m4d は全国家AIで操作できる国家がない)
cargo run --bin map_economy_session -- --actor 1           # 操作国家を明示(手動国家のみ)
cargo run --bin map_economy_session -- --shots <dir>       # 自動スクリプトで画面を保存して終了
```

## 4. 操作主体

- 既定は**未選択**。`--actor` と画面の国家ボタンは同じ `apply_command(SetActor)` → `EconomySession::resolve_actor` を通る(テストで両経路の結果が一致)。
- 未選択: 地図の閲覧・経済情報の参照は可能。「操作国家: 未選択」と「日付を進めるには操作国家を選択してください」を表示し、日付進行は拒否される(理由を結果欄に表示)。
- AI国家・存在しない国家は選択を拒否し、**現在の選択を維持**(別の国家へ置き換えない・先頭国家へのフォールバックなし)。AI国家のボタンは暗い色で「(AI)」と表示され、押すと「AI国家のため、操作国家に選べません」と出る。国家はボタンの国家ラベルで識別し、表示順は使わない。
- 国家変更は操作主体だけを変える(経済・日付は不変: テスト)。他国家のステートは「他国家のステートです(閲覧のみ。操作国家ではありません)」と表示。

## 5. 画面項目と日付の意味

上部帯: 見出し(【検証用】新マップ 経済セッション・シナリオ名・「正式な世界設定・ゲーム開始ではありません」)、処理済み日付/次に処理する日、操作国家、国家ボタン、選択解除、「+1日/+7日/+30日」。
右パネル(既存の選択セル説明の下): 操作国家の国庫・税率・人的資源・月次収支・経済状態・備蓄・建設キュー件数、選択ステートの名称・対応国家・人口・労働力比率・生活水準・不満度・雇用/失業・物流・施設(稼働率)。下部帯: 直近6件の操作結果(○成功/×失敗)。「建設・保存の操作は後続の段階(S2・S3)で追加します」を表示。
- **日付**は「最後に処理を完了した日」。開始直後は「未処理(開始日 1800/01/01)/次に処理する日: 1800/01/02」。
- **未計算を0にしない**: 月次の値(雇用・失業・物流・稼働率・月次収支・経済状態)は最初の月次処理(開始月と別の月になった日)まで「未計算(最初の月次処理前)」と表示(開始時の雇用0・物流使用0等は未計算の初期値)。人口・施設・国庫・生活水準などシナリオ入力は常に表示。
- 選択対象: 経済ステート/シナリオの経済に含まれないステート/未割当/検証範囲外/水域/地図外/選択なし。切り替わるたびに全て作り直し、前のステートの情報・対象は残らない(テスト)。内部型名・ダイジェストは表示しない(テストで検査。既存の選択セル欄は従来どおり「MapState#20」等を表示)。

## 6. コマンドの受付と適用

`SessionCommand::{SetActor(Option<u32>), AdvanceDays(u32)}`(Bevy `Message`)。
1. ボタンは `Interaction` の `Changed`(押した瞬間の1回)でコマンドを**発行するだけ**(状態は変えない)。押し続け・ホバーでは重複しない(テスト)。
2. `apply_session_commands` が到着順に1つずつ `apply_command` で適用(唯一の更新経路)。
3. **操作主体の検証は適用の時点**(その時点の選択に対して)。同一フレームに [進行, 国家選択, 進行, 解除, 進行] が来ると 拒否/成功/成功/成功/拒否 の順で、1日だけ進む(テスト)。
4. `AdvanceDays(n)` は 1〜30 日(`MAX_DAYS_PER_COMMAND`=30。ボタンは 1/7/30)。1コマンドとして `advance_day` を n 回同期的に連続し、その間に他のコマンド・描画は入らない。日次・月次の処理は共有の `advance_day` のみ(UIで再実装しない)。
5. 拒否(未選択・AI・日数が範囲外)は状態を一切変更しない(テスト: 状態の全体比較)。
- **保証範囲**: `advance_day` は `Result` を返さず失敗経路が無いので「途中までの進行」は発生しない。ただしロールバック・保存はせず、プロセスが途中で異常終了すれば状態は失われる(この画面はそれ以上を保証しない)。
- 初回表示・表示モード変更・セル選択・国家選択・描画更新では日付は進まない(120フレーム空回し等のテスト)。自動の連続進行は無い。
