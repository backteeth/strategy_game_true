## 境界の生成と描画の方式
GUI 非依存の `compute_boundaries` が、ステートに属する各プロヴィンスの 6 辺を調べる(辺の定義は河川と同じ `river_edge_world`=セル描画と共通の座標変換):
| 種別 | 条件 | 出力 | 描画 |
|---|---|---|---|
| `StateBorder` | 隣が別ステート | **1 辺 1 件**(`(q,r)` が辞書順で小さい側のみ)。同じステート内部の辺は出さない | 白の太線(暗い縁取り付き)、河川より上 |
| `ToUnassigned` | 隣が未割当プロヴィンス | ステート側から 1 件 | 橙の細線 |
| `ToOutOfScope` / `MapEdge` | 隣が表の対象外の陸 / 地図の外 | 同上 | 紫の細線 |
| `Coast` | 隣が水域 | 出力はするが**描画しない**(海岸線は地形の塗りで見えるため) | なし |
描画順(z): 塗り 0 < ヘックス境界線 1 < 外周線 1.4 < 河川 1.5/1.6 < **ステート境界 1.65/1.7** < 選択枠 2/3。色は河川=水色、ステート境界=白、選択枠=黄+黒縁で判別できる。
メッシュは全体で 3 枚の帯メッシュ(縁取り/本体/外周線)で、チャンクに分けないため、チャンク境界や負の q でも欠落・二重がない(テストで確認)。線幅は画面上で約 2.4px/1.4px を保つよう、ズーム段階(√2 刻み)が変わった時だけ作り直し、パン中や同一段階のズームでは再構築しない。ステート境界は `B` キー/ボタンで切替(既定は表示)。
ステート塗り(`4` キー/ボタン、ワールド設定がある場合のみ表示): ステート色は ID から決まる(黄金比の色相。起動のたびに変わらない)、未割当=明るい灰、検証範囲外の陸=地形色を暗くしたもの、水域=従来の水色。地形/気候/植生モードは従来どおりで、どのモードにも境界を重ねられる。
