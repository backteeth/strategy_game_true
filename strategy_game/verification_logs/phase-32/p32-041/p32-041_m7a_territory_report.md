# P32-041 (M7-a) ステート単位の領土移転と国家消滅

基準コミット: 4ced96d。P32-040 の M7 設計書 §5〜7 の第一案(D5 第一案、V1〜V6 の提案)に沿った実装で、**未承認の仕様をユーザーが承認したものではない**(今回の指示で実装方針として指定された範囲)。
所有・支配・首都・交戦関係は検証入力で、正式な世界データではない。範囲は移転・消滅・戦闘中止・師団の帰還・補給の整合まで。**戦争記録・休戦・戦争点数・降伏・経済帰属・セーブ(M8)は後続の単位へ引き継ぐ**(§6)。

## 1. 実装(`src/world/territory.rs`、純粋な Rust・Bevy 非依存)

- `Territory`: 実行時の法的所有(`MapStateId` → 国)、国家ごとの**首都の正本**(`ProvinceId`)、国家の存続(`Active` / `Eliminated { annexed_by }`)、適用回数(`revision`)。ステートの所属は `WorldModel` を参照し、旧 `StateId` と数値で対応付けない。
  補給の首都は同じ値を参照する(首都が変わるとき同じ値で `MapMilitary::set_capital`。`check_consistency` で一致と、消滅国の補給設定が残っていないことを確認)。シナリオからは `Territory::from_scenario`(`state_owners`・国家の対応表・補給の首都)。
- `plan_transfer`(状態を変えない。作業用の複製に同じ処理を行って結果 `TransferPlan` にする)→ `apply_transfer`(**適用の直前に現在の状態で同じ検証をやり直し**、結果が計画と一致したときだけ適用)。検証はすべて変更の前に済み、適用の本体は途中で失敗しない。日次処理(`advance_day`)の間に呼ぶ。
- 要求 `TransferRequest { state, expected_owner, new_owner, cancel_battles }`。拒否 `TransferError`: 未知のステート/国家、所属プロヴィンスなし、消滅済みの国家、現在の所有国が期待と違う、同じ国、未知の戦闘、移転ステート内の戦闘が中止対象に未指定、首都の候補なし。
  適用の拒否 `ApplyError`: `AlreadyApplied` / `Stale`(`TerritoryChanged` = 別の移転のあと、`Invalid(..)` = 現在の状態では要求が成り立たない、`OutcomeChanged` = 結果が計画と違う)。
- 新設した小さな API: `MapMilitary::cancel_battles`(明示した戦闘の中止)、`CancelledBattle`、内部用の `remove_wars_of`・`remove_supply_country`。

## 2. 採用した規則

| 項目 | 規則 |
|---|---|
| 移転 | 対象ステートの法的所有を移し、所属**全プロヴィンスの実効支配を新所有国にそろえる**(旧 `transfer_region_ownership_unchecked` と同じ)。変更を `ControlChange`、解消した**第三国**(元の所有国でも新所有国でもない国)の占領を `third_party_resolved` に記録 |
| 首都(正本) | 国家ごとの `ProvinceId`。首都が移転ステート内にあり、元の所有国に法的所有のステートが残るなら、残るステートを `MapStateId` 昇順に調べ、最初に「元の所有国が支配する有効なプロヴィンス」があるステートの代表地点へ。**代表地点 = ステートの `representative`(自国支配下なら)、なければ自国が支配する最小の `ProvinceId`**。候補がなければ `NoCapitalCandidate{country}` で拒否(何も変えない) |
| 国家消滅 | 最後の法的所有ステートを失った国は `Eliminated`(ID は保持・削除しない)。首都を持たなくなり、師団は解散(`DisbandReason::CountryEliminated`)、その国が当事国の交戦関係と補給の設定を取り除く。その国が参加する進行中の戦闘は自動で中止。移転地以外でその国が支配していたプロヴィンスは、そのステートの法的所有国(存続していれば)の支配へ戻し、無ければ支配国なし |
| 戦闘の中止 | 要求の `cancel_battles` に**明示した戦闘だけ**を中止(勝敗・占領・損失・回復なし。参加師団は戦闘中 → 待機、戦闘参照を外す)。移転ステート内に進行中の戦闘があるのに明示がなければ拒否。無関係な戦闘は維持。単独の `cancel_battles` は未知・進行中でない・重複を拒否し何も変えない |
| 師団の帰還 | 移転ステート内にいる師団のうち、所属国が新所有国でなく、かつ**新所有国と交戦していない**国の師団。帰還先 = **隣接する自国支配のプロヴィンス(`ProvinceId` 昇順)→ 自国支配の最小 `ProvinceId`**(どちらも進行中の戦闘がない地点)。帰還先がなければ**解散**(`DisbandReason::NoReturnProvince`。戦闘による撃破 `Destroyed` とは別)。帰還した師団は経路・目的地・進捗を破棄して待機。**交戦中の国の師団は残す**(別の戦争で敵領内にいる師団を除く旧 `peace.rs` の規則に相当。M7-a は戦争を終結させないため。戦争終結に伴う帰還は M7-b 以降が同じ規則に交戦の条件を加えて呼ぶ) |
| 移動命令 | 帰還した師団以外の命令は触らず、次の `advance_day` の経路検証が再判定する |
| 補給の無効化 | 実効支配が変わったプロヴィンスの変更前と変更後の国(**第三国を含む**)、首都が移った国、消滅した国。次の補給計画で新しい首都と支配から再計算される(`invalidated_countries` に記録) |

## 4. 自動検証(`tests/p32_041_territory_test.rs`、18 件)

補給の再計算(次の補給計画が新しい首都と支配から算出、消滅国は計画されない)/ 戦闘の明示中止と未指定の拒否・単独の中止の拒否と状態保持・無関係な戦闘の維持・消滅国の戦闘の自動中止 / 移動命令の扱い / 帰還先の規則(隣接優先 → 最小 ID → 解散)/
不正な要求の一覧の拒否と**状態の完全一致**(`Territory` と `MapMilitary` の `==`)/ 古い計画・適用済みの計画の拒否(`AlreadyApplied`・`TerritoryChanged`・`OutcomeChanged`・`Invalid`)/ 補給の首都の不一致の検出 /
**入力順に依存しない**(シナリオの各リストを逆順にしても、結果・最終状態が一致。中止指定の順序・重複も同じ計画)/ 旧経路との比較 / 師団プレビューでの移転。

旧経路との比較(旧 `state::ownership`・`country::elimination` を旧型の fixture で実行。新旧 ID の対応: 旧 `StateId k` ↔ 新 `MapStateId 20+k`、国家は共通の `CountryId`): 拒否の種類(CurrentOwnerMismatch/SameOwner/CountryNotFound/StateNotFound ↔ OwnerMismatch/SameOwner/UnknownCountry/UnknownState)、
**首都の再配置**(旧は残る州の最小 `StateId` → 新は対応するステートの中の代表地点)、適用後の所有・支配、**拒否時の状態保持**、最後のステート(旧 `LastOwnedLandState` → 消滅の preflight ↔ 新の消滅)、国家 ID の保持が一致。

## 6. 後続の単位へ引き継ぐもの

- 戦争の記録(識別・戦争目標・終結)・休戦・戦争点数(D6c)・降伏・勝敗(M7-b 以降)。M7-a は交戦関係を終わらせない(移転は戦争を終結しない)。戦争終結に伴う帰還・占領の正常化は、`Territory`/帰還の規則に交戦の条件を加えて呼ぶ。
- 経済の帰属(D6b)、人口・建物・建設注文の移転、`ECONOMY_RULES_REVISION`、保存(M8。`Territory` の保存形式、消滅状態)、請求・危機(外交)の整理。
- 確認していない規則・限界: 帰還の対象は移転ステート内の師団だけ(消滅国の旧占領地を所有国へ戻したプロヴィンスにいる他国の師団は対象外)、第三国の占領を維持する案(D5-2)は未実装、国家の消滅日は持たない(日付の概念が新経路にない)、首都は補給の設定がない国家にも持てるが、シナリオからは補給の首都だけが入力される。
- 実行時に変わる法的所有を `MapMilitary` の外の `Territory` に置いた(`MapMilitary` は支配だけを持つ)。呼び出し側が両方を渡す。M7-b 以降で戦争の記録を加えるときに、1 つの状態にまとめるかを再検討する。
