- `src/hexmap/division_view.rs`(新規)
  - `DivisionSession`(Bevy 非依存): 既存のシナリオローダー(`load_division_scenario`)で初期化した `MapMilitary` + `ProvinceGraph`。選択・移動命令・1日進行は既存の `issue_move_order` / `advance_day` を呼ぶだけ(再実装なし)。
  - `DivisionCommand`(`Message`)を到着順に 1 件ずつ適用。コマンドが無い限り日付も軍も進まない。
  - UI(上部帯・下部帯・右パネルの欄)とマーカー描画。世代(セッション識別 + 軍/選択の世代)が変わったときだけ描画物を作り直す。

- 保存・アセット・旧ゲームのプラグインは使わない。

## 2. 表示

- 師団マーカー: プロヴィンスごとに 1 つ。位置は現在の `ProvinceId` の所属セルから決める(複数セルのプロヴィンスは**重心に最も近いセル**、同距離は `(q, r)` が小さいほう。入力順に依存しない)。国家ラベルで色分け。同じプロヴィンスに複数師団がいれば `xN` を表示。
- 選択中の師団: 黄色の枠(同じプロヴィンスに複数いれば、選択した師団を含むマーカーに枠)と、移動中なら目的地に白い菱形。
- 支配の印: 法的所有国(ステートの所有。検証入力)と異なる国が実効支配しているプロヴィンスに、支配国の色の小さな四角。
- 右パネルの「師団(検証用)」: 所属国・現在地(ステート)・**法的所有国(ステート)と実効支配国(現在地)を別項目**・状態(待機/移動中/戦闘中)・移動中なら目的地・次のホップ先・今のホップの進捗・人員/組織率/補給充足率・同じプロヴィンスの師団・選択セルにいる師団(ID 順)。ステート単位の支配(P32-038 の集計。法的所有と実効支配を別々)も出す。
- 下部帯: 操作結果(命令の受理/拒否と理由、日次の出来事、支配の変化、見送り、撃破による選択解除)。

## 3. 操作(画面にも表示)

| 操作 | キー | ボタン |
|---|---|---|
| 師団を選ぶ | PageUp / PageDown(MapDivisionId 順に巡回) | 上部帯の「師団N (国家X)」、「前の師団」「次の師団」 |
| 選択解除 | X | 選択解除 |
| 移動先を指定 | 地図で左クリックしてセルを選ぶ(既存のセル選択) | — |
| 移動命令を出す | M | 選択セルへ移動 |
| 1日進める(`advance_day` を 1 回) | Space / N | 1日進める |

- 検証モードは停止状態(0 日目・未選択)で始まる。
- 拒否された命令は理由を結果欄に出し、既存の経路・進捗は変えない(`issue_move_order` は受理時だけ状態を変える)。
- 選択した師団が移動・退却しても選択は維持。撃破されたら選択と詳細表示を解除し、理由を出す。
- `Tab` は既存どおり画面を閉じる/開く。閉じるとセッションを破棄し、開き直すとシナリオを読み直して初期配置から始まる。
- パネル・帯・ボタンはすべて `Button`(`Interaction` を発行)なので、既存の入力抑止(`ui_is_hovered`・`DragState.started_on_ui`)により、UI 上のクリック・ドラッグ・ホイールは地図(セル選択・パン・ズーム・移動命令)へ渡らない。既存のキー(1〜4・G・R・B・F・Home・Tab・Esc)とは重ならない。
