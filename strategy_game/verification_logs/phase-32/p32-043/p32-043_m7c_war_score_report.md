# P32-043 (M7-c) 戦争点数・降伏判定
基準コミット c8759a6。実装は `src/world/war_score.rs`(純粋な Rust・Bevy 非依存)。**判定結果を返すところまで**で、結果を使った講和の適用は M7-d。休戦の既存ルールを維持した理由は P32-042 報告書 §8。

## 1. 規則(`war_score.rs` の冒頭にも記載)
- **占領率(S 案)**: 陣営 X の代表国 pX が、相手の代表国 pO が**法的に所有する**ステートそれぞれで「pX が支配するプロヴィンス数 ÷ 所属総数」を求め、**単純平均**する。
  所属 0 件のステートは除外。第三国・支持国・支配国なしのプロヴィンスは分母に含み、分子には入れない(代表国の支配だけが占領)。
- **丸めない**: 平均は既約分数(`u128`)で持ち、60% 以上は `分子×10 ≥ 分母×6` の整数比較。占領点は `⌊占領率×40⌋` を整数除算で一度だけ切り捨てる。ステートごとの途中丸め・入力順に依存しない(テストあり)。分数が `u128` を超える病的な入力は `RateOverflow` で拒否する。
- **対象陸ステートが 0 件**(相手の代表国の所有ステートが 0 件、または所属 0 件だけ): 占領率は**定義しない**(`None`)。占領点は 0、60% の条件は**不成立**。
- **点数(攻撃側視点)**: 目標ステート全域を攻撃側代表国が支配で +40。攻撃側占領点 − 防御側占領点(どちらも `⌊率×40⌋`)。戦闘点 = 勝利数の差 × 5 を ±20 に収める。総点は ±100 に収める(収める前の合計も出す)。
- **戦闘の集計(`BattleLedger`)**: `MoveEvent::BattleFinished`(勝敗が確定した戦闘)を `MapBattleId` ごとに一度だけ数える。中止された戦闘は終了イベントを出さず、守備隊のいない占領は `ControlClaim` だけなので数えない。
  交戦国の組を両陣営に持つ稼働中の戦争が**ちょうど 1 件**のときだけ計上し、0 件(従来の組だけの敵対など)・複数件は計上せず理由(`SkipReason::NoWar` / `Ambiguous(候補)`)を残す。スキップした戦闘も再計上しない。
  勝者(攻撃国か防御国か)が戦争のどちらの陣営かで加点側を決める(支持国の戦闘も計上)。旧と同じく、組織の脱落・両者消滅・損失 0 による防御側勝利も確定した結果として数える。
- **降伏**: 防御側 = 目標全域を攻撃側代表国が支配 **かつ**(攻撃側の占領率 ≥ 60% **または** 防御側代表国に戦闘可能な師団がない)。攻撃側 = 防御側の占領率 ≥ 60% **または**(戦闘可能な師団がなく、防御側代表国が攻撃側代表国の所有ステートを 1 件以上全域支配)。
  戦闘可能 = 人員が 0 でない師団(新経路は撃破した師団を除去するので旧の定義と同じ)。双方成立なら総点 > 0 で防御側、0 以下で攻撃側。終結済みの戦争は `AlreadyEnded`(`assess_active_wars` は稼働中だけ、`MapWarId` 昇順)。
- 判定は読み取り専用(`Territory`・`Conflicts`・`MapMilitary` を変えない。テストあり)。

## 2. 旧経路との比較(意図した差)
全域支配だけのケース(旧のステート単位の支配と同じ粒度)は、旧 `calculate_war_score` / `evaluate_war_capitulation` と**内訳・総点・降伏判定が全件一致**(7 通りの支配 × 3 通りの師団の有無 × 4 通りの戦闘結果。`full_control_only_cases_match_the_old_path_for_score_and_surrender`)。
意図した差:
1. **部分占領を扱う**: 旧はステートの支配国が 1 つなので 7 プロヴィンス中 1 件の占領は表せない(0 点)。新は 1/7 を平均に入れ ⌊40/7⌋ = 5 点。
2. **占領率の単位**: 旧は「ステート数の割合」、新は「ステートごとのプロヴィンス割合の平均」(S 案)。13 プロヴィンスと 7 プロヴィンスのステートでは、片方を全部取っても平均 1/2(プロヴィンスの合計比 65% / 35% とは別)で、60% に達しない。
3. **陸ステートが 0 件**: 旧は降伏(攻撃側は自領 0 件で降伏、防御側は 0 件なら即降伏)。新は占領率を定義せず条件にしない(国の消滅は M7-a/b が扱う)。
4. **比較は厳密**: 旧は `f32` の 0.60 との比較。新は整数の比較で、丸め誤差の入る余地がない。
5. 戦闘の帰属: 旧は戦闘が戦争 ID を持つ。新の戦闘は戦争 ID を持たないので、交戦国の組から一意に決まるときだけ計上する(複数候補は計上せず理由を出す)。
6. 防御側の降伏で「目標が未設定」なら旧は不成立。新の戦争記録は目標が必須なので該当しない。

## 3. 再現(CLI。`strategy_game/` で。`--war-score` を付けると、各日の終わりに内訳・降伏理由・計上しなかった戦闘が出る)
シナリオ A(`division_war_scenario.ron`)を使用。国家2 が攻撃側、国家1 が防御側の戦争1(目標ステート22)。
- `cli_01_initial_scores.txt`: 初日(day 0)。戦争1 は防御側(国家1)が国家2 のステート21 を 3/13 占領(⌊40×3/13⌋ = 9 点)。総点 −9、降伏なし。国家3・4 の戦争は所有ステートなし(占領率は定義しない)。
- `cli_05_target_held_only.txt`: 国家2 が目標(ステート22)だけ全域支配。+40 + 平均 1/2(+20)− 9 = 51、占領率 50% で降伏しない。
- `cli_02_defender_surrenders.txt`: 国家2 がステート22・20 を全域支配 → 占領率 100%・目標全域 → **防御側の降伏**(理由: 目標全域 + 占領率 ≥ 60%)。総点 71。
- `cli_03_both_sides.txt`: 上に加えて国家1 がステート21 を全域支配 → 双方の条件が成立。総点 40 > 0 なので**防御側が降伏**(理由を両方表示)。
- `cli_04_battle_ledger.txt`: 国家1 の師団14 が 17486 を攻撃(25 日)。戦闘の勝敗が台帳に一度だけ入り、戦争1 の戦闘点 −5(国家1 = 防御側陣営の勝利)になる。
師団の有無・複数候補・二重計上は CLI でなくテスト(下記)で確認した(CLI で師団を消す手段はない)。
