## 3. 生産能力の再構成
- 実走の全国・全月(3600 件)で、月初の再構成値が同月の実産出と **完全一致(不一致 0)**。entry ごとの量子化も一致。
- 値の意味: 「直近の記録済み稼働率 × **現在の**建物レベル × 基本出力による、現設備の推定持続能力」。直近月の実産出そのものではない。AI 判断は産出処理と同一フレーム(産出直後)で行われるため、判断時点では実産出と一致する。それ以外の時点では所有・レベル変化後の現設備で再構成するため、過去設備の産出を混ぜて過大評価することは無い。稼働率の記録が無い(レベル>0)州は 0 として数える(過大評価しない側)。Load 後も記録済み稼働率から同じ値が再構成される(P29-004 の save/load テストで確認済み)。
- 契約と矛盾する実装は見つからなかったため、実装は変更していない。

## 5. Elfin 対 Dwarf+Passguard が 70 日分に届かない理由(標準シナリオ・600 か月)
- Elfin の 1817/04 以降の戦争期間(394 か月): 平均月産 210.2 に対し、8 個目時点の必要量 273.75。月産が必要量以上の月は 148/394(38%)。月末備蓄が 1 未満の月は 248/394。最大備蓄日数 32.8 日(70 日=630 に未到達)。期間の純増は合計 +204.6(月平均 +0.5)。
- 原因は **MilitaryFactory 稼働率の周期変動**: 例(1817〜1818)op=0.93 の月が 2〜3 か月続いたのち 0.43〜0.53 へ落ち、0.62〜0.66 を経て 0.93 に戻る(約 4 か月周期)。低稼働月は Iron 備蓄が 87〜92 → 52〜56 に低下し、IG 備蓄が 97〜122 → 209〜224 に一括補充される月と一致する(Iron/IG の入力配分の周期)。労働力 0.93、物流 1.00 は一定で原因ではない。
- 8 個目の注文(1817/03/01)の判定は 能力 281.72 > 需要 273.75(余裕 3%)で、これは周期の高稼働月の値。持続平均(約 210)とは 25% 乖離する。
- 切り分け:
  - 備蓄回復の余剰が小さい: 該当(高稼働月でも純増 +0.3〜+9.5、2 月のみ +27)。
  - 月平均換算では能力内だが実収支は不足: 該当(換算は 365/12 日、高稼働月の 1 点の値で判定)。
  - 能力推定と実産出の乖離: **主因**。同月内の再構成は一致するが、1 か月の稼働率は持続値を代表しない。
  - 需要増・生産減で余剰喪失: 該当(募兵完成で需要が段階的に増え、低稼働月で備蓄が 0 へ戻る)。
  - AI 評価周期: 非該当(月次で毎月評価、理由は常に SupplyShortage、blocked=true)。
  - 補給以外の判断: 非該当。
- 28〜31 日の実消費と ceil(日次×365/12) の差は最大でも月あたり 1 未満〜数単位で、上記の欠損(月 60 以上)に比べ無視できる。

### 次の設計変更の候補比較
| 案 | 内容 | 評価 |
|---|---|---|
| A(推奨) | 能力推定を単月の稼働率ではなく **直近 N か月の記録の最小値または平均**で算出(持続能力の保守的推定) | 原因(1 点推定の過大評価)に直接対応。稼働率履歴の持続化が必要(additive フィールド、非破壊)。N は次タスクで標準シナリオ比較して決定 |
| B | 需要に安全率(余裕)を要求 | 新しい数値が必要で、周期の振幅(±30%)に対して小さい余裕では効かず、大きいと免除外の成長を止める |
| C | 低稼働の根因(Iron/IG 配分周期)を解消 | 根本策だが生産会計に踏み込むため単独タスクが必要(今回の範囲外) |
| D | 戦時の MilitaryFactory 建設トリガ強化 | 供給不足の長期化には効くが、周期変動そのものは残る |
| E | 戦時募兵の保留 | 戦力増を止めるだけで備蓄回復は改善しない |
推奨: A → C の順。A で「持続できない注文」を許可しなくなり、C で稼働率の周期を解消する。
