## 5. Arcadia の原料(Iron)調達可能性
(`p29_011_arcadia_iron_availability` と既存の記録)
- **資源**: Arcadia の初期の所有州(0・1・2・11・12)のうち、**Iron 鉱床があるのは首都の州 0 だけ**(基本出力 50、Coal 40、discovered)。他の 4 州に Iron 鉱床はない。
- **Mine**: AI は 1800/01/02 に州 0 の Mine lv1 を着工し、1800/03/03 に完成した(「Mine がない」ではなく、一度は建設・稼働している)。ただし州 0 の労働力・物流の稼働率 t が 0.09〜0.13 と低く、Mine の稼働率 0.13・産出は月 7 程度で、Iron 消費(月 19)を賄えず、備蓄 200 が約 18 か月で枯渇した。
- **領土**: 州 0 は 1800/06/04 開戦の Dwarf 対 Arcadia(目標 StateId(0))の 1801/03/27 の降伏で失った。以後、Arcadia の所有州に採掘可能な Iron 鉱床はなく、Mine の候補にも入らない(鉱床なしの州は候補から除外される既存規則)。
- **調達経路**: 交易・輸入・移送の機能は**存在しない**(`src/` に該当モジュールなし)。Iron を得る手段は、州の領有(戦争の目標)だけである。
- **分類**: **資源条件上、国内供給できない**(領土喪失後)+ **必要な調達機能(交易・移送)は未実装**。「既存経路で供給可能だがAIが利用していない」には該当しない。資源を持たない国の存在自体は不具合ではない。B1 の対象拡張・資源追加・輸入機能は今回行わない。
