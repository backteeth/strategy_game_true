# P29-003：長期停滞した AI 戦争の白紙講和

P29-003-DIAG-001 が推奨した E1 を、限定的な AI 和平経路として実装した。軍事的進展が長期間なく、一方の陣営が無力で、他方も攻勢を開始できない AI 同士の戦争を、既存の白紙講和 API(`execute_peace_settlement`、`settle_capitulation` 経由)で終結させる。

```text
P29-003 COMPLETE
E1 IMPLEMENTED（停滞期間 365 日、AI 同士の戦争のみ、既存の白紙講和 API を使用）
ISS-1: 終結する(1811/12/06、停滞白紙講和)
ISS-2: 標準シナリオでは発生しなくなった(世界が分岐。同型の戦争は 365 日で終結)
NEW RESIDUAL: 両陣営に師団がある戦争の相互膠着(Dwarf+Elfin 対 Ferrowyn、1812/02/02)は対象外のまま継続
THE ROOT CAUSE (募兵が持続的生産能力を超える問題) IS NOT RESOLVED
MANUAL VERIFICATION PENDING（P29-002 の残存手動確認を含む）
```

## 2. 採用した和平条件

実装: `src/war/stalemate.rs`(新規)、`src/war/update.rs` のステップ 3.6。

白紙講和には、次の**すべて**を要求する。

| # | 条件 | 実装 |
|---|---|---|
| 1 | 長期間、実際の軍事的進展がない | 進展の署名(`progress_signature`)が **365 日**(`STALEMATE_WHITE_PEACE_DAYS`)変化せず、その間に進行中の戦闘もない。署名 = 戦闘の集計値(攻撃側・防御側の勝利数、処理済み戦闘数)+ 占領州の集合 + 参加国が関わる「所有者 ≠ 支配者」の州の組(州ID・所有者・支配者)。**評価処理が走ったこと・前線計画の再生成は署名に含まない**。戦闘の発生(進行中の戦闘は毎日リセット)と州の支配変更が進展 |
| 2 | 一方の陣営に師団が存在しない | 陣営全体(主要国と支持国)で、生存師団(兵力 > 0 かつ撃破でない)を集計。支持国の師団がある陣営は「無力」と扱わない。**両陣営に師団がある戦争は対象外** |
| 3 | 他方も現在の既存攻勢条件を満たせず、攻勢を開始できない | 武装している側について、(a) 移動中・戦闘中・退却中・占領中の師団がない、(b) 前線計画が Offensive でない、(c) 軍事 AI の直近判断が `SufficientAdvantage` でない。いずれかに該当すれば停滞扱いにしない(進行中の攻撃・戦闘を妨げない) |
| 4 | 既存の和平判定を通る | 陣営の代表国どうしの白紙講和提案として `can_accept_peace_offer` を通す(開戦 30 日以上、戦勝点 ≥ −10 等)。万能の自動終戦ではない |
| 5 | 双方が AI | プレイヤーが主要国・支持国のいずれとしても参加する戦争は対象外(記録も持たない)。`war_goals` が空の戦争も対象外(P28-007 と同じ扱い) |

- **停滞期間 365 日**: 診断報告書に具体的な推奨値がなかったため、指示の初期案を採用した。理由は、ISS-1・ISS-2 が 16,000 日・9,400 日継続し、1 年は短期の膠着と区別できる十分な長さで、通常の短期戦争(5〜254 日)を巻き込みにくいため(長期化した WarId(3)[3,926 日]は、§6.1 のとおり E1 の影響を受けず従来どおり降伏で終結した)。ISS-1・ISS-2 に合わせた国別・WarId 別の条件は持たない。
- **日数の計算**: 既存の `GameDate::days_since`(年 365 日・月 30 日の暦近似)。同日付の 1 年後でちょうど 365 日になる。
- **「進展」の範囲**: 当事国が関わる**別の戦争の**支配変更も、その国が関わる限り進展として数える(当事国が他の戦場で戦っている間は、停滞とみなさない)。これは設計上の選択であり、§6 に影響を記録した。
