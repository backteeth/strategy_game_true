## 2. 今回確認する項目(手動確認待ち)

### A. New Game から戦争・講和までの通し操作

1. `cargo run` で起動、国家選択で任意の国(例: Dwarf Federation)を選び New Game。
2. 内政: 国家経済パネルで税率・国庫・収支が表示される。月が替わると値が更新される。
3. 建設: 州を選び建物(例: Factory)を発注 → 日数の経過で建設キューが進み、完成すると建物の Level が増える。
4. 募兵: 軍事パネルで Division を募兵 → 完成まで約 30 日 → 師団数と補給需要(下記 B)が更新される。
5. 戦争・講和: 外交パネルで宣戦(正当化が必要)→ 戦争一覧に表示 → 講和パネルで白紙講和などを提案 → 一覧から消える。結果(領土・前線・休戦)に異常がない。
- 期待: 画面のエラー・固まり・表示の欠落がない。

### B. 補給収支 UI(P29-002 の残存確認 = PENDING のまま)

- 開始直後(1800/01/01): 「前回の月次生産(実績): 未集計(次の月次生産後に表示)」。需要・備蓄日数は表示され、0・NaN にならない。
- 1800/02/01 を越える: 実績が 0.0 または実績値(対象年月つき)に変わる。再クリック不要。
- 年越し(1800/12 → 1801/01): 対象年月の表記が正しく更新される(自動確認のみ。手動未確認)。

### C. セーブ / ロード(**先にユーザーの Save を退避**)

1. 任意の日付で Save → 数日進める → Load。日付が Save 時点へ戻り、国・資金・師団・戦争が復元される。
2. ロード後、補給収支の実績が「未集計」へ戻り、次の月初に再表示される(P29-002 の仕様)。
3. ロード後に進めて、戦争・建設・募兵が続く(固まり・欠落がない)。
- 完了後、退避した Save を戻す。
