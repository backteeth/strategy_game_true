# P31-004 プロトタイプ候補の安全な手動確認環境

確認対象コード: `1136c213bdeefe8e756cb2a34f34cc2cf7a40af7`(P31-003)。**本番コードとバランスは変更していない**(このタスクで追加したのは、起動スクリプト 2 本・人工 Save の生成テスト 1 本の追加と更新・本書)。
実画面の確認結果はまだない。**すべて手動確認待ち**。起動準備ができただけで「基本プロトタイプ完成」とは扱わない。

## 1. ユーザーの Save から分離できた根拠

| 確認 | 結果 |
|---|---|
| Save の保存先 | `SavePathConfig::default()` = `PathBuf::from("saves/savegame_v1.ron")`(`src/save/write.rs`)。**起動時の作業ディレクトリからの相対パス**。一時ファイルは同じ場所の `savegame_v1.ron.tmp` |
| データの読み込み先 | `std::fs::read_to_string("assets/data/*.ron")`(`src/app/loader.rs`)。**作業ディレクトリからの相対パス**。言語ファイルとフォントは実行ファイルに埋め込み(`include_str!` / `include_bytes!`)で、ファイルを読まない。Bevy の `AssetServer` は使っていない |
| 他に書き込むファイル | 製品コードでは Save のみ(`src/bin/profile_1000_states.rs` は別の計測用バイナリで、ゲームとは無関係) |
| 実験 1(assets のない空ディレクトリで起動) | 起動直後に `[DataLoader] Failed to read assets/data/buildings.ron ... Make sure to run the game from the project root directory.` で終了(終了コード 101)。**作業ディレクトリ相対で読んでいる**ことの直接の証拠。空ディレクトリには何も作られなかった |
| 実験 2(隔離環境 normal / m1 / e1 から起動、各 12 秒) | 3 環境ともゲームプロセスが 12 秒間動き続けた(assets を作業ディレクトリのコピーから読んで起動)。起動だけでは Save を書かない: `normal\saves\` は空のまま、`m1\`・`e1\` の人工 Save は更新されなかった(サイズ・更新日時が生成時のまま) |
| ユーザーの Save | `saves\savegame_v1.ron`(リポジトリ直下)は**内容を読んでいない・書いていない・移動していない**。実験の前後で、サイズ(68,779 bytes)と更新日時(2026-09-09 10:51:42 UTC)のメタデータが不変であることだけを確認した |

結論: 作業ディレクトリを `target\manual_check\<環境名>` にして起動すれば、読み書きするのは、その中の `saves\` と `assets\` だけ。**原本 Save の退避・差し替えは不要**。

## 2. 準備と起動

### 2-1. 構成(すべて `target\manual_check\` の下。`target` は git の除外対象)

### 2-2. 手順(PowerShell。リポジトリの `strategy_game` ディレクトリで)

```powershell
# 1 回目だけ、または確認対象コードをビルドし直したいとき: ビルド・人工 Save の生成・環境の組み立て
powershell -ExecutionPolicy Bypass -File scripts\manual_check\prepare.ps1

# 起動(環境ごと)
powershell -ExecutionPolicy Bypass -File scripts\manual_check\run.ps1 normal
powershell -ExecutionPolicy Bypass -File scripts\manual_check\run.ps1 m1
powershell -ExecutionPolicy Bypass -File scripts\manual_check\run.ps1 e1
```

| 項目 | 内容 |
|---|---|
| 実行するファイル | `scripts\manual_check\prepare.ps1`(準備)、`scripts\manual_check\run.ps1 <normal\|m1\|e1>`(起動) |
| 起動時の作業ディレクトリ | `target\manual_check\<環境名>`(`run.ps1` が設定する) |
| 実行ファイル | `target\release\strategy_game.exe`(`prepare.ps1` が `cargo build --release` で作る。DLL は `target\release\deps` を PATH に加えて解決する) |

| Save の読み書き | `target\manual_check\<環境名>\saves\savegame_v1.ron` |
| 確認対象コードの識別 | `prepare.ps1` が、`src`・`assets`・`Cargo.toml`・`Cargo.lock` が `1136c213…` と一致し未コミットの変更がないことを確認し、一致しなければ中止する。`target\manual_check\BUILD_INFO.txt` に、確認対象コード・HEAD・実行ファイルの SHA256 と更新日時・人工 Save の SHA256 を記録する。`run.ps1` は起動時にこれを表示し、実行ファイルの SHA256 が記録と違えば(再ビルドされていれば)中止する |

注意: `run.ps1` は、そのコンソールをウィンドウを閉じるまで使う。ゲームのウィンドウのタイトルは `Grand Strategy - Prototype v0.3`(コード由来の識別子はウィンドウには出ない)。

## 5. M1・E1 の画面確認(人工 Save。**人工的な確認条件**)

通常プレイでの自然な発生とは区別して記録する。どちらも、プレイヤーは Passguard(戦争に関与しない国)。人工 Save は、実 New Game に、AI 同士の戦争(Dwarf 対 Arcadia)を制御 fixture として追加し、毎日戦力を固定して作ったもの。**Load 後は、ゲームの通常の AI・日次処理だけで進む**(生成テストが、この経路で期待どおり終結することを確認済み)。

### 5-1. M1(`m1` 環境)

- 起動: `run.ps1 m1` → 国家選択画面の「続きから」(Continue、保存済みのゲームを読み込む)を押す(または、いったん「ゲーム開始」で入ってから上部バーの「ロード」)。
- 人工条件: Dwarf と Arcadia の AI 戦争(戦争名 `P31-002 mutual stalemate fixture`)。**両国に同じ戦力の師団 2 個ずつ**で、730 日間、戦闘・占領がない(双方武装・双方に攻勢の意思なし)。
- Save の日付: **1801/12/28**(発動の 5 日前)。**期待する発動日: 1802/01/02**(最後の進展の 730 日後)、終結理由 `Mutual Stalemate White Peace`(白紙講和)。
- 操作と期待結果:
  1. Load 直後は一時停止。Ctrl+3(外交)の「-- 進行中の戦争 --」に、上の戦争があることを確認する(Dwarf 対 Arcadia)。
  2. 一時停止を解除し(`Space` または速度ボタン)、1802/01/02 を越えるまで進める。
  3. 一覧から**その戦争が消える**。領土の移転がない(地図で Arcadia の州の所有が変わらない)。前線表示(`F` キー)にこの戦争の前線が残らない。他の戦争・国の状態(上部バー・補給収支)に異常がない。固まり・エラーがない。
  4. (任意)終戦の直前(1801/12/30 など)にセーブし、終戦後にロードして、同じ日に終戦することを確認する。
- 注意: AI 同士の戦争の終結は、プレイヤー向けの通知・休戦表示(Ctrl+4 の「有効な休戦」は自国の休戦のみ)・終結理由の文字列は画面に出ない。画面で確認できるのは、一覧から消えること・領土や前線に異常がないことだけ。

### 5-2. E1(`e1` 環境)

- 起動: `run.ps1 e1` → 「続きから」。
- 人工条件: Dwarf と Arcadia の AI 戦争(戦争名 `P29-003 stalemate fixture`)。**両国とも師団 0**(一方が無力)で、365 日間、軍事的進展がない。
- Save の日付: **1801/08/09**(発動の 5 日前)。**期待する発動日: 1801/08/14**(最後の進展の 365 日後)、終結理由 `Stalemate White Peace`。
- 操作と期待結果: M1 と同様(1 → 一覧に戦争がある、2 → 1801/08/14 を越える、3 → 一覧から消える・領土移転なし・前線に異常なし)。
- 注意: E1 の人工 Save は、ゲームでの自然な発生(AI 同士の戦争で一方に師団がなく 365 日進展がない)の代わりではない。**M1 の確認をもって E1 を PASS にしない**(別々に記録する)。

### 5-3. 通常プレイでの自然な観測(任意)

`normal` 環境で、プレイヤーが戦争に関与しない国として長く進め、Ctrl+3 の一覧で AI 同士の戦争が約 365 日(E1)・730 日(M1)後に消えるのを観測できれば記録する。起きる時点・組は、プレイの経過で世界が分岐するため保証されない。観測できなければ「該当なし」と記録する(合否ではない)。
