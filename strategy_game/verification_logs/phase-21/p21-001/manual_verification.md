# P21-001 手動・描画確認記録

本ドキュメントを作成した各セッションで利用可能なツールには、GUIウィンドウへのマウス操作・
スクリーンショット取得を行う自動化手段(ブラウザ/computer-use系ツール等)が含まれていない。
そのため、指示された手動確認項目のうち、実機での**インタラクティブなクリック操作確認は
セッション内では実施できていない**。「実施した」と偽って報告することは避け、以下の通り
実施済み/未実施を明確に分けて記録する(2026-08-10追記: 下記「ユーザーによる実機確認」
セクションにより、この制約下で保留していた項目はすべて解消された)。

## 実施済み(自動テストによる代替確認)

以下はBevy ECSレベルでの自動テストにより、実機起動なしで機能的に検証済み:

1. **RecruitButtonが軍事パネルのUIツリーに実際にspawnされること**
   → `ui::military_panel::tests::recruit_button_is_spawned_in_military_panel_ui_tree`
   (`setup_military_panel`を実行し、`RecruitButton`コンポーネントが1件存在することを
   ECSクエリで確認。従来は`RecruitButton`を実際にspawnする箇所が存在せず、この確認自体が
   不可能だった)。

2. **実行可能条件を満たすと正式な募兵経路(`request_recruitment`)へ到達すること**
   → `handle_recruit_buttons_success_queues_recruitment_and_deducts_cost`
   (`Interaction::Pressed`を直接設定して`handle_recruit_buttons`システムを実行し、
   資金・人的資源の正しい減算と`recruitment_queue`への追加を確認)。

3. **実行不能条件(州未選択/他国州/資金不足/人的資源不足/未知の部隊定義)では
   ゲーム状態が一切変更されないこと**
   → `handle_recruit_buttons_no_selection_does_not_mutate_state` ほか5件
   (各条件で`Interaction::Pressed`を設定してもCountryRegistryの状態が完全不変であることを
   確認)。

4. **同一州に複数師団が駐留する場合、クリック位置に応じてどちらの師団も個別に選択できること**
   (2026-08-10追加)
   → `map::army_selection::tests::army_display_positions_offsets_stacked_armies`
   (描画側のスタックオフセット計算を切り出した`army_display_positions`が、同一州の2師団に
   異なる表示座標を割り当てることを確認)、
   `map::army_selection::tests::handle_army_selection_can_pick_either_stacked_army`
   (`handle_army_selection`システムを`MinimalPlugins`で実行し、2師団それぞれの表示座標を
   クリックすると、クリックした側の師団が選択されることをECSレベルで確認。従来は
   州の中心固定座標でしか判定しておらず、常にHashMap走査順で決まる一方しか選択できなかった)。

## 部分的に実施(自動化の範囲内)

5. **実機起動によるスタートアップ確認**: `cargo run --release`を約20秒間実行し、正常に
   ウィンドウが生成されGPU(RTX 5070 Ti, Vulkan)が認識され、`[DataLoader] Successfully
   loaded 8 buildings, 22 technologies, 4 countries, 10 states, 3 diplomatic relations`まで
   到達し、ERROR/WARN/panicが一切出力されないことを確認した
   (`manual_launch_smoke_test.log`)。ただしタイムアウトで強制終了しており、
   国選択→ゲーム開始→軍事パネルを開く、という一連の操作までは到達していない
   (マウス操作の自動化手段がないため)。

6. **Headless実GPU描画テスト(P20-007、保護対象・無変更)**: `ui_headless_render_test.rs`が
   本番`UiPlugin`込みの全プラグイン構成で実GPU描画を行い、PASSしていることを`cargo_test.log`
   で確認済み。ただしこのテストはP21-001以前から存在する固定チェックポイント
   (国選択画面・Playing画面の基本要素)のみを検証しており、募兵ボタン個別のピクセル検証は
   行っていない(保護対象のため本タスクでは追加のチェックポイントを増設していない)。
