これを求めると要衝・袋小路・突出部という今回の設計目標と正面から矛盾するため、
「大陸全体が単一の陸塊として連結している」という、より一般的な不変量に書き換える方針とした。

## 1. 新興2か国の設定案

既存4か国(Kingdom of Arcadia / Elfin Republic / Dwarf Federation / Oceanic Magic Empire)の
命名パターン(「[形容]+[統治形態]」、`map_color`はRGB各0.0〜1.0)に合わせて提案する。
いずれも後で自由に変更可能。

### 新興国A: パスガード辺境国 (Passguard March)
- 統治形態案: `Monarchy`(小規模な辺境領主国)
- `map_color`案: `(0.52, 0.52, 0.60)`(灰青、既存4色と明確に区別できる山岳・石造りの配色)
- 首都: State 15「Highvale(ハイヴェイル)」
- 設定: Arcadia北方の山岳地帯にある小さな辺境国。唯一の外部接続路である
  State 13「Mountain Watch」の関所を軍事的に管理することで存続してきた、寡兵ながら
  地の利で自立を保つ小国。

### 新興国B: フェロウィン自由同盟 (Ferrowyn League)
- 統治形態案: `Republic`(自治都市の同盟)
- `map_color`案: `(0.82, 0.68, 0.15)`(琥珀・金、既存4色と区別できる交易国の配色)
- 首都: State 22「Free Watch(フリーウォッチ)」
- 設定: Arcadia・Dwarf・Oceanicの三国境が接する回廊地帯に自治都市群が結成した
  同盟国家。鉱山と交易路を扼する立地で、大国間の緩衝地帯として独立を保っている。

いずれも`economic_system`・`treasury`・`stockpile`等の細部は実装時に既存4か国の値を参考に
設定する(本追補では未確定)。

## 3. 構造検証(スクリプトによる機械検証)

手計算による隣接関係の誤りを避けるため、上記の隣接構造をスクラッチパッド上のPerlスクリプトで
機械検証した(リポジトリ内のファイルは一切変更していない)。結果:

- ✅ 28州全てが単一の陸塊として連結(孤立州なし)
- ✅ 6か国全ての所有州が連続領域を形成(飛び地なし)
- ✅ 双方向隣接: 全エッジで相互参照を確認
- ✅ 自己隣接なし
- ✅ 袋小路(次数1の州): 10, 17, 18, 20, 25, 27 の6州(要求「2つ以上」を満たす)
- ✅ 突出部: State 12「Frontier Fort」(友軍隣接1、敵国隣接3: Dwarf×2 + Ferrowyn×1)
- ✅ 要衝(関節点): State 13を除去すると{10,15,17}の3州が本土から切断される
  ("State 13を落とせばパスガードの奥3州へ到達できなくなる"という明確な軍事目標になる)
- ✅ 広い国境(3州以上の相互隣接エッジ): Arcadia-Dwarf間4本、Dwarf-Elfin間3本、
  Dwarf-Ferrowyn間4本の計3箇所
- ✅ 複数経路: 例えばArcadia⇔Dwarf間だけで「0↔5」「2↔5」「2↔19(Ferrowyn経由)」
  「12↔5」「12↔6」など多重の経路が存在

## 4. `land_war_combat_peace_test.rs`(保護対象)の書き換え方針

6か国化により、このテストの書き換えが避けられないことを確認済み(§0-8)。
具体的な変更点(実装時の方針、今回はまだ変更していない):

```rust
// 変更前
assert_eq!(country_ids.len(), 4, "Expected 4 countries in countries.ron");
// 全ペア (c1, c2) について直接隣接をassert

// 変更後(方針)
assert_eq!(country_ids.len(), 6, "Expected 6 countries in countries.ron");
// 「全州(海洋州を除く)が単一連結成分をなす」ことをBFS/DFSでassertする関数に置き換え
// (§3で機械検証した性質そのものを、テストとしても自動検証する形になる)
```

この書き換えは保護対象ファイルへの変更のため、実装に進む前に改めてこの方針で
良いかご確認ください(本追補の提示だけで承認済みとみなしてよいか、実装着手時に
diffを見てから最終承認するか、お好きな方で構いません)。
