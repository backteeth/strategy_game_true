## 4. 補給とMilitarySuppliesの内訳(区別して記載)

用語は次のとおり区別した。

- 国の備蓄: `stockpile`のMilitarySupplies値。
- 実月産: `100 × 工場Level × 稼働率`(その月の`building_operation_ratios`)。
- 全師団の日次需要: `country_daily_demand_units`(単位は整数units、1.0/日=1,000,000 units)。
- 各師団への配分と充足率: `division_supply_fulfillment`(日次配分の結果)。
- MilitaryEquipment・manpower・organizationの補充は別系統で、補給充足率とは別に扱う。

## 6. 軍需工場の稼働率を決める式と制約段階

実コード(`src/economy/production.rs`):

```text
稼働率 = clamp( min(労働力比, 物流比, 入力資源充足率) × (破産中なら0.8) , 0, 1 )
労働力比 = 雇用労働力 / 総労働力(0除算は1.0、[0,1]へクランプ)
物流比   = state.logistics_ratio
入力資源充足率 = min over 入力資源( clamp(国家備蓄 / 月間必要量, 0, 1) )
  月間必要量 = Σ 全建物 入力量 × Level × min(労働力比, 物流比)   ← Step 1
実産出 = 基本産出 × Level × 稼働率   (MF: ME 20 + MS 100 /Level)
入力消費 = 基本入力 × Level × 稼働率   (MF: Iron 30 + IndustrialGoods 15 /Level)
```

3つの制約はそれぞれ別の段階で効く(最小値を取る)。実測で各段階が支配した例:

| 制約 | 実測例(観測日・国・州) | 数値 |
|---|---|---|
| 労働力 | 90日 Arcadia state0 | 稼働率0.103 = 労働力比0.103(物流1.00) |
| 労働力 | 90日 Ferrowyn state26 | 0.384 = 労働力比0.384 |
| 物流 | 90日 Dwarf state6 | 稼働率0.235 = 物流比0.235(労働力比0.274) |
| 入力資源(IndustrialGoods) | 90日 Elfin・Oceanic・Passguard | IG備蓄0.0 → 充足率0.000 → 稼働率0.000(労働力比0.04〜0.93) |
| 入力資源(Iron) | 120か月 Dwarf | Iron備蓄45.3 / 月間必要205.2 = **0.221**、IG充足率1.000。州0・6・19の稼働率0.221(労働力比0.268・0.390・0.948)で全州同値 |
| 入力資源(Iron) | 120か月 Arcadia | Iron 0.0 / 70.6 → 0.000 |

- 月次生産の直前日(月末)に、同じ式(Step 1-2)で入力充足率を再計算して上表の値を得た。Dwarfの稼働率0.221は、Iron充足率0.221と一致する。
- 稼働率が低い期間のDwarfのIronの推移(`mine_lvl`は一定の12): 1806/01 1413.8 → 1807/01 1012.2 → 1808/01 273.5 → 1809/01 48.7 → 1810/01 48.9。IndustrialGoodsは同期間に2,730→5,074と**積み上がり、使われていない**。Factory Levelは11→15に増えた。Ironの収支は、鉱山産出が消費(Factory増設分を含む)に追いつかない状態に見える。
- 注意: 稼働率が入力不足か破産(×0.8)かは式の上では区別できないが、Dwarfの国庫は15,176で破産ではない。

**「約20%」の説明**: 再現シナリオのDwarf 120か月は稼働率0.195〜0.221で、Iron入力不足により説明できる。手動プレイが同じかどうかは**未確定**。
