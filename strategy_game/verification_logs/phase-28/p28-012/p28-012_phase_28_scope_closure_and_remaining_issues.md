## 6. 生産量と 70 日分備蓄の記述の整理(PRE-003 の補足)

PRE-003 §3.1 の「70 日分への到達条件は `P ≥ 71·D`(月産 ≥ 71 × 日次需要)」は、**成立する前提が限定されている**。既存報告書は変更せず、ここに補足する。

記号: `P` = 月産、`D` = 日次需要(1 Division = 1/日)、`N` = その月の日数、`S₀` = 月初の生産後・当日消費後の備蓄。一定の `D`・`N = 30`・`P` 一定の単純化。

| 場合 | 条件 | 月内最大備蓄(月初の当日消費後) | 70 日分(`70·D`)への到達 |
|---|---|---|---|
| **(a) 毎月備蓄が枯渇する(月産 < 月需要)** | `P < N·D`(30 日月で `P < 30·D`) | 定常状態では `S₀ = P − D`(前月末が 0 のとき)。この値が月内の最大で、以後は日々 `D` ずつ減る | **到達できない**。`P − D < (N−1)·D ≤ 30·D < 70·D`。`P ≥ 71·D` は `P < 30·D` と両立しないため、この枝で「到達条件 `P ≥ 71·D`」を満たす状態は存在しない(PRE-003 §3.1 の「P < 30·D」の枝の記述は、到達不能を意味するものとして読む) |
| **(b) 月産が月需要を上回り、数か月の余剰蓄積で到達** | `P ≥ N·D`(30 日月で `P ≥ 30·D`) | 月ごとに `P − N·D` ずつ増える。`S₀(k) = S₀(0) + k·(P − N·D)` | 前月末が 0 のとき `S₀(0) = P − D`。到達までの月数は `k = ⌈(71·D − P) / (P − 30·D)⌉`。`P ≥ 71·D` なら**初月で到達**(`k = 0`)。つまり「`P ≥ 71·D`」は**零から 1 か月で到達する十分条件**であり、余剰が数か月続くなら必要ではない |

数値例(一定需要・30 日月の算術であり、実測ではない):

- Ferrowyn 8 Division(`D = 8`、`30·D = 240`): 現在の `P = 133` は (a)。到達不可。MilitaryFactory を Lv3 にして `P = 266` なら (b) で `k = ⌈(568 − 266)/(266 − 240)⌉ = 12` か月。ただし ISS-4 のとおり、余剰は募兵に吸収され得る。
- Dwarf 16 Division(`30·D = 480`): `P = 362〜468` は (a)(P/30D = 0.75〜0.98)。到達不可。

実ゲームとの差:

| 項目 | 単純化 | 実ゲーム |
|---|---|---|
| 月の日数 | 30 日 | 暦月(28〜31 日)。`N` が大きい月ほど (a) の赤字が深く、2 月は浅い |
| 需要 `D` | 一定 | Division の完成(募兵 30 日後)で、完成の翌日から +1/日 |
| 月産 `P` | 一定 | 前月の稼働率(労働力比・物流比・入力充足率の最小)で変動。MilitaryFactory の建設・人口・戦争で変わる |
| 評価時点 | 連続 | AI の攻勢評価は 3 日周期。月初に 70 日分を超えても、超過日数 `(S₀ − 70·D)/D` が評価間隔より短いと見逃す(WarId(5): `(789 − 770)/11 ≈ 1.7` 日) |
| 備蓄の起点 | 零 | 平時の蓄積があれば (a) の領域でも、数か月は 70 日分を超えて減少する(WarId(5) の 1808/08、WarId(9) の 1820/01 までの Ferrowyn) |

したがって WarId(9) の結論(Ferrowyn は到達不能)は変わらない。変わるのは「到達条件 `P ≥ 71·D`」の読み方だけである。
