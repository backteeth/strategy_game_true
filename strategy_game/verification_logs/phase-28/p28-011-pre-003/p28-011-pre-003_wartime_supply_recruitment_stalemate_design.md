### 要旨

1. **WarId(9) を止めているのは攻勢ゲートの 70日しきい値そのものではなく、Ferrowyn の月産(約 133)が月需要(8 Division = 240)の 55% しかないこと**である。この比率では、募兵を止めても止めなくても、月初の最大備蓄は `P − D ≈ 125`(15.6日分)で、70日分(560)には届かない。到達条件は `P ≥ 71·D`(= 月需要の 2.37 倍)で、**8 Division の Ferrowyn では不可能**。
2. **赤字戦力を作ったのは平時の募兵**。Ferrowyn は 1809/02 に MilitaryFactory が Lv2 になって月産 145 > 需要 60 となり、備蓄が **5,359(1814/02)** まで積み上がった。1814/04/30 の 5個目から月需要が月産(141)を超え始めたが、募兵ゲートは備蓄(5,300 前後。900日分超)を見て許可し続け、**1819/03/30 に 8個目**まで増やした(募兵開始日 1819/03/01 の備蓄 1,574 = 225日分)。備蓄は 1814 年から月 10〜110 ずつ減り、**1820/05 に 128 で下げ止まり**(以後は月初 125、月末 0)。戦争が始まった 1824/04/02 には、攻勢ゲートは初日から閉じていた(109 = 13.6日分)。

## 3. 保存式と到達可能性(推測ではなく式と実測)

記号: `P` = MilitaryFactory の実月産(前月の稼働率で計算)、`D` = 日次需要(Division 数)、`S₀` = 月初の生産後・当日消費後の備蓄。

### 3.1 月次の推移

```text
S(月末) = max(0, S(月初) + P − 30·D)        // 月内で日次消費が連続する
S₀(翌月初) = S(月末) + P − D                  // 月初の生産と当日の消費
```

- **P < 30·D(赤字)**: `S(月末) = 0` に収束。`S₀ = P − D`(Ferrowyn: 133 − 8 = 125、実測 124.6〜125.9)。**攻勢の再開しきい値 `70·D` に届く条件は `P ≥ 71·D`**。8 Division では `P ≥ 568`(実測 133)。1 Division なら `P ≥ 71`(届く)。
- **P ≥ 30·D(黒字)**: 備蓄は月 `P − 30·D` ずつ増える。`70·D` に届くまで `⌈(71·D − P) / (P − 30·D)⌉` か月。Ferrowyn が D=4、P=133 なら約 12か月(`(284−133)/13`)。

### 3.2 募兵を止めただけでは回復しない

| 国・時点 | D | P | 月需要 30·D | P/30D | 募兵を止めた場合の `S₀` | 70日分 `70·D` | 回復 |
|---|---|---|---|---|---|---|---|
| Ferrowyn 1820/05 以降 | 8 | 133 | 240 | 0.55 | 125(=P−D) | 560 | **不可能**(Division は減らない。募兵ゲートは評価もされない) |
| Dwarf 1809/02 以降 | 16 | 362〜468 | 480 | 0.75〜0.98 | 345〜452 | 1,120 | **不可能**(488 → 349 に下がり、以後 345〜470 で推移) |
| Dwarf 1808/08(募兵前) | 11 | 377 | 330 | 1.14 | 789(71.7日) | 770 | **到達していた**(ここから募兵で消費された。§3.3) |

Division は消滅(戦闘損耗)でしか減らず、AI に解隊の判断はない。したがって「P < 30·D」の状態は、一度作られると**募兵ゲートが何をしても解消しない**。

### 3.4 なぜ Ferrowyn の WarId(9) は 40/70 の差では説明できないか

Ferrowyn は 1814〜1819 年の募兵を**平時**(停止 20日 / 再開 35日)に行い、備蓄は常に 5,000 → 1,500(900〜225日分)で、再開線にも停止線にも触れていない。1820/05 以降は目標Division数への到達で募兵が評価されない。停止線 40日も再開線 70日も、募兵の挙動を左右していない。**Ferrowyn にとっての 70日は攻勢ゲートの要求だけ**であり、その到達不可能性は P/D の比で決まる(§3.1)。

### 5.1 候補同士の重複・統合

- **候補B(戦時)= B1**。P28-004-PRE-001/002 の硬い生産量ゲートと判定式・結果が同一(§6 で再現確認)。「平時と戦時の適用範囲を分ける」ことは BP / B1 / B2 で実測した。
- **A12 ≈ B1**(結果は 360か月までビット一致、600か月で Dwarf の Division が 21 と 20 の差)。12か月先を見ると、備蓄が 70日分以下の実在の国家では `S` が小さく、B1 とほぼ同じ判定になる。独立した案ではない。
- **A1 は B1 とは別物**(備蓄 S を式に含む)。A1 は備蓄が十分あれば許可する(Ferrowyn の 1814〜1819 年の募兵は許可する)。
- **C1 と C2 は 120か月まで同一**。240か月から分岐(Dwarf の補給不足 C1: 85,507 / C2: 57,638)。C2 は限定版で、本命。
- 「40日・70日の定数を下げる案」「補給ゲートを無効化する案」「全AIの日次評価」は対象外(指示どおり採用候補に含めない)。

### 5.2 候補A がなぜ Ferrowyn の平時の募兵を止められないか(式)

1819/03/01 の 8 個目: `S = 1,574`、`P = 137`、`D_cur = 7`、`d_new = 1` → `S + P − 30·7 − 1 = 1,500 ≥ 70·8 = 560` で**許可**。1 か月の収支を見る限り、備蓄が 5,000 の国家の募兵は常に安全に見える。A12(12か月)なら `1,574 + 12·(137 − 240) = 338 < 560` で拒否する(8 個目は止まり、7 個で停止。ただし 7 個でも `P < 30·7`、赤字は残るため WarId(9) 型の停止は残る。§7.3 の A12all 実測)。

### 5.3 候補C の実測(Ferrowyn、1824/04 から C2 を有効化)

MilitaryFactory 建設が 1824/10 頃に完成し、MF Lv3、稼働率 0.83〜0.88、月産 250〜264 になる。月需要 240(8 個)に対し 1.04〜1.10。備蓄は 1825/01 の 268 から月 +8〜+16 で増え、1827/01 に 499(62日分)に達する。**1827年中盤に 9 個目が完成し(人口増による目標の増加)、備蓄が 538(1827/07)→ 395(1828/01)に下がり、70日分に届かない**。WarId(9) は C2 だけでは終結しない。C2 に A1 を足した C2A1 では 9 個目が保留され、**1827/05/01 に 71.3日分で攻勢が開始され、1827/05/05 に AttackerVictory**(開戦から 3年1か月)。

## 8. 境界・Save・決定性

推奨できる候補はないため、本節は**候補Bの平時適用(BP/B2)または候補A1/C2 を採用する場合の契約と、一時パッチの実測で確認できた範囲**を示す。

| 項目 | 結果・契約 |
|---|---|
| 備蓄が判定境界と等しい場合 | 本診断のパッチは浮動小数の `<` で判定した(B 系: `P < 30·D'` の等号は許可 = 満たす側、A 系: `<` で等号許可)。本番化する場合は **MilitarySupplies の正規 units(整数)で比較し、`≥` を許可側とする**(既存の `has_reserve_for_days` と同じ規約。P28-002 の入力判定も `≥`)。境界値の恒久テスト(`P = 30·D'`、`S = 70·D'` の前後 1 unit)を必須とする |
| Division 完成当日と翌日の需要 | 募兵キューは需要を生まない。完成(MilitaryAction Set)は日次消費(Economy Set)の後なので、**完成当日の消費は旧 D、翌日から新 D**(RECRUIT_START と DIVISION_COMPLETE の `dem` が 30 日の差で +1 になることを実測) |
| 月次生産直前・直後の募兵判断 | 募兵は月初の生産・当日消費の後に評価される(`handle_monthly_economy` → CountryAi)。P と S は同一フレームで確定しており、順序依存はない。ただし `P` は前月の稼働率(`building_operation_ratios`)で、**当月の稼働率ではない**ことに注意(建設・人口・戦争で変動し得る) |
| 戦争開始・終結時の条件切替 | B1・A1(戦時のみ)は `is_country_at_war` を毎回再評価する純粋条件で、永続状態を持たない。宣戦当日から切り替わる |
| Division が 0 または 1 個の国家 | **B 系は MilitaryFactory を持たない国家(P=0)を恒久的に増員不能にする**(`P < 30·d_new` が常に真)。実測: B2/BP は 240か月まで全6か国が Division 1 のまま戦争が 0 件。Oceanic(MF なし)は B2 で 600か月まで 3 個に留まる |
