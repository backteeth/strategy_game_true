# P28-004-PRE-003 平時の過剰募兵による長期補給停止の設計監査

P28-004-PRE-002が独立課題として記録したwar9型(平時に生産で支えられない規模まで募兵し、開戦後に恒久的な補給不足で停止する)について、P28-005・P28-006-PRE-001後の本番状態で、平時の募兵を抑える候補H・G(90/180/365日)・Sを比較した設計監査である。本番コード・RONデータ・既存テストは恒久的に変更していない。一時パッチと一時診断は検証後に完全に除去した(§9)。

## 1. 総合判定

```text
P28-004-PRE-003 ANALYSIS COMPLETE
PEACETIME OVER-RECRUITMENT ROOT CAUSE CONFIRMED
DESIGN USER DECISION REQUIRED
P28-004 IMPLEMENTATION BLOCKED
```

- **PEACETIME OVER-RECRUITMENT ROOT CAUSE CONFIRMED**: `calculate_ai_target_divisions`(人口の10%であるmanpower基準上限の50%を目標Division数とする)は、生産能力を一切参照しない。平時の募兵はP28-004-PRE-002のB1(交戦中のみ制限)でも制約されないため、人口が増え続ける限り目標Division数も増え続け、MilitaryFactoryの拡張が追いつかない規模まで募兵が進む。Dwarfは平時に11個Divisionまで拡大し(月需要330に対し月産115〜353の間を往復、一度も持続的に上回らない)、開戦後に恒久的な`SupplyShortage`(実測5,050日、約14年)で停止することを確認した。
- **DESIGN USER DECISION REQUIRED**: 4種類の候補(H・G90・G180・G365・S)を実測したが、**war9型を完全に解消し、かつ他の指標を悪化させない候補は見つからなかった**。H・Sは平時の募兵を事実上凍結し240か月間戦争が1件も起きない(P28-004-PRE-001のA_allと同じ副作用が、P28-005後も再現)。G90〜G365は戦争を維持するが、6か国合計の補給不足日数が悪化し、G365に至ってはArcadiaが領土縮小の末にP28-005-PRE-001と同型の長期財政死のスパイラルに陥る(税率1.00、国庫−39,078、1830年から恒久的にLS0)。**問題を解消できない候補を、テストが通るだけで採用しない**という指示に従い、いずれの候補も推奨しない。
- **P28-004 IMPLEMENTATION BLOCKED**: ユーザーが§7の2択に回答するまで、募兵条件の本番実装はしない。

## 3. 実コードの再確認

`rg`で以下を確認した(過去報告書の式をコード確認の代わりにしていない)。

| 段階 | 実コード | 内容 |
|---|---|---|
| 目標Division数 | `military::ai::calculate_ai_target_divisions` | `floor(cap/2)/required_manpower`(最低1)。`cap = compute_manpower_cap(population)`(人口の10%)。**生産能力を一切参照しない** |
| 募兵判断順序 | `military::ai::decide_and_recruit_for_country` | ①キュー非空→見送り②帳簿不整合→見送り③目標到達→見送り④補給ゲート(備蓄・配送)⑤manpower不足⑥募兵州選択。P28-004-PRE-002・P28-006-PRE-001の記述と一致、無変更 |
| 補給ゲート | `military::recruitment_supply_gate::evaluate_recruitment_supply_gate` | 停止20日(平時)/40日(戦時)、再開35日/70日のヒステリシス。**月次生産量(フロー)を見ない**、無変更 |
| 訓練完了 | `military::recruitment::request_recruitment`→`process_recruitment`(日次) | 歩兵30日。完成翌日の日次補給から需要1.0/日が加わる、無変更 |
| 月次生産 | `economy::production::process_country_production` | 実月産=100×MilitaryFactory level×稼働率。`Economy`Set(`CountryAi`より先)で確定するため、募兵判断はその月の最新値を読む(P28-004-PRE-002・P28-006-PRE-001で確認済みの実行順、再確認して不変) |
| 戦時MilitaryFactory着工 | `country_ai::try_wartime_supply_construction`(優先度2.5) | **戦時のAI国家だけ**が対象。平時は一切発火しない(`process_construction_ai_with_wartime_supply`の`wartime_supply`引数がNoneのとき経由しない) |
| Railway建設 | `country_ai::try_logistics_railway_construction`(優先度2.7、P28-005) | 物流比率0.9未満の州を対象とし、MilitaryFactory拡張そのものには関与しない |

**確認した事実**: 平時のAI国家がMilitaryFactoryを自発的に建設する経路は存在しない(優先度2は原材料/IndustrialGoods用のMine/Factory、優先度3もMine/Factory[経済用]であり、いずれも`BuildingType::Factory`であって`BuildingType::MilitaryFactory`ではない)。MilitaryFactoryの拡張は、戦時の優先度2.5だけが担っている。これはP28-006-PRE-001でS候補がH候補と完全に同一の結果になった直接の原因である(§4.4)。

### 5.4 H候補とS候補が完全に一致する理由

§3で確認したとおり、平時のAI国家はMilitaryFactoryを自発的に建設する経路を持たない。S候補の条件(「MilitaryFactoryが建設キューにあれば今回は許可する」)は、平時には常に「キューにない」ため`H`と数学的に同一の判定になる。実測でも`H.log`と`S.log`は`FIS`行が1バイトも違わず完全一致した。**S候補は、平時にMilitaryFactoryを自発的に建てる仕組みが別途存在しない限り、Hと区別できない**。

## 6. 境界・Save(推奨候補が未確定のため簡略)

推奨できる単一候補が存在しないため、§6の全項目を1候補について詳細検証することはしていない。ただし、以下は候補の構造から明らかである。

- **Divisionが0個・1個の場合**: 既存の目標Division数判定(③)が先に評価されるため、候補の影響を受けるのは目標未達の国だけ(既存の挙動と同じ)。
- **月産0・未確定**: `military_supplies_value_to_units`のエラー時は安全側(見送り)に倒す設計(P28-004-PRE-002・本監査のパッチとも同じ規律)。
- **月産と募兵後需要が等しい境界**: `>=`判定(黒字扱い)、既存のP28-002/P28-004-PRE-002と同じ規約。
- **New Gameから最初の月次生産まで**: `Economy`Setが`CountryAi`より先に実行されるため、New Game直後の初回評価でも実月産0の状態(募兵前)を正しく読む。
- **Save V1**: いずれの候補も`state_registry`・`military_registry`・`country.construction_queue`から毎回再計算する純粋条件であり、新規永続フィールドは不要(既存の`SkippedSupplyShortage`を再利用)。G候補の「不足を埋められる日数」も、現在備蓄と現在の需給差だけから毎回導出するため、過去の募兵履歴を保存する必要はない。
- **プレイヤー国家・消滅国家**: 既存の`evaluate_ai_monthly_recruitment`の除外(`is_active()`かつプレイヤー以外)がそのまま適用される、候補側での特例なし。
- **決定性**: G90を独立プロセスで再実行し、`FIS`行が完全一致することを確認した(決定的)。

## 7. 設計判定・ユーザー判断

いずれの候補も、war9型の解消と他指標の維持を同時に満たさない。**最大2案**に絞り、数値とともに提示する。

### 案1: 現状(B0)を維持する(推奨)

| 指標(600か月) | 数値 |
|---|---|
| 補給不足日数(6か国合計) | 32,798(基準) |
| 財政 | 全国安定(P28-005の効果を維持) |
| war9型の継続戦争 | 存在する(240か月で2件、うち1件は13.8年間膠着) |
| 開戦・戦争頻度 | 自然なまま |

推奨理由: 今回試した候補はいずれも、war9型を解消する代わりに、戦争頻度そのもの(H・S)か、財政・補給不足の総量(G90〜G365)のいずれかを悪化させた。war9型自体は特定の2か国がまれに膠着する局所的な問題であり、6か国全体の財政・戦争ループを犠牲にするほどの実害ではないと判断する。

### 案2: G90を採用する

| 指標(600か月) | 数値 |
|---|---|
| 補給不足日数(6か国合計) | 33,408(+1.9%、ほぼ同水準) |
| 財政 | 全国安定(P28-005の効果を維持) |
| war9型の継続戦争 | 短縮される見込みだが完全には解消しない(240か月時点で開戦から日の浅い同型の戦争が残る) |
| 開戦・戦争頻度 | B0よりやや活発(240か月で13戦争、B0は10) |

推奨理由: G-系の中で唯一、財政を崩さず(G180・G365は崩す)、600か月時点の補給不足日数もB0とほぼ同水準に収まる。ただし、war9型を明確に短縮・解消したという確証は得られておらず(§5.5)、既存の戦争頻度・戦闘数を変える副作用を受け入れる必要がある。

**問い**: war9型(局所的だが13年超続く膠着)を許容範囲内の既存の欠陥として維持するか(案1)、それとも戦争頻度・戦闘数の増加という副作用を受け入れてG90を採用するか(案2)。
