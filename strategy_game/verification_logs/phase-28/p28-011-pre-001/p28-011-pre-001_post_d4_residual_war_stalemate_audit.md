## 1. 要旨

1. 600か月で継続する戦争は2件。**どちらも敵に戦闘可能な Division がいない(敵戦力 0)のに、攻勢を一度も開始していない。**
   - **WarId(5)**: Elfin+Dwarf 対 Arcadia、1806/03/02 開戦、戦争目標 州2。Dwarf の16個の Division が 44年間 Idle。
   - **WarId(9)**: Ferrowyn 対 Oceanic、1824/04/02 開戦、戦争目標 州23。Ferrowyn の8個の Division が 26年間 Idle。
2. **最初に塞がる判定は「攻勢開始の国家備蓄ゲート」**(`offensive_supply_blocked`、再開しきい値 = 日次需要 × 70日分)。前線・割当・経路・戦力比・装備・配送(前線)・国境・戦争目標は、いずれも成立している。
3. **ゲートが開かない理由は、MilitarySuppliesの月産が需要を下回る定常状態にある**(Dwarf: 月産 379〜437 / 需要 480、Ferrowyn: 月産 129〜145 / 需要 240)。備蓄は月初に生産が入り、月末までに0になり、ピークでも 15〜28日分で、70日分に届かない。
4. **戦争前の補給の余裕は、募兵に使い切られる**。Dwarf は 1808/08 に備蓄が初めて 70日分を超え(789 / 需要11 = 71.7日)、募兵ゲートが開いて Division が 11→16 に増え、需要が生産を超えて以後ずっと 70日分に届かない。
5. **決定的な近接原因(WarId(5))**: 備蓄が 70日分を超えたのは 1808/08/01〜08/02 の**2日間だけ**で、AI の評価は3日周期(07/31 → 08/03)のため評価されなかった。08/03 には 767 < 770(70日分)に戻っていた。同日から日次評価にした制御診断では、1808/08/01 に攻勢を開始し、**14日後の 1808/08/15 に勝利で終結した**。
6. D0 → D4 の差: D4 は Ferrowyn の WarId(8)(1819/02/02)を5日で終結させた(D0 では備蓄 0 で継続)。一方、D4 後の WarId(9) は Ferrowyn の月産が需要の 55% しかなく、同じゲートで停止する。**D4 は Iron 配分の改善であり、MilitarySuppliesの総量の不足そのものは解決しない。**
7. P28-010-PRE-003 の「war5 決着」は、予算超過の副産物だった(IMPL-002 §6)。本監査では基準値に使っていない。

### 4.1 一時的か恒久的か

- **WarId(5): 1806/03/03 〜 1850/01/01(約16,000日)で攻勢開始ゼロ。** 例外は 1808/08/01〜02 の2日間(§5)で、AI が評価しなかった。以後 42年間、月初のピークは最大 470(28日分)で、再開しきい値(70日 = 1,120)の 42%。

- 「600か月で継続中」という事実だけで永久停止とは断定していない。この構成(生産 < 需要、募兵ゲートが 40日分で止まる)が続く限り恒久的、と実測の傾向(26〜44年間、変化なし)から判定した。

### 6.1 なぜ生産が需要に追いつかないか

1. **募兵ゲートの停止線(40日分)と攻勢開始(70日分)は、同じヒステリシスの別の値**(`WARTIME_STOP_DAYS` = 40、`WARTIME_RESUME_DAYS` = 70)。募兵は備蓄が 70日分に達すると再開し、**40日分を割るまで続く**。募兵が止まった時点の需要は「備蓄 40日分を維持できない」規模で、その定常状態の備蓄は 40日分以下になる。つまり**募兵が止まる状態では、攻勢開始(70日分)に到達できない**。
2. **生産は月に1回、月初にまとめて入る**ため、日次需要に対し、備蓄日数は月内で 0〜28日の範囲を往復する。
3. **MilitaryFactoryの増設が止まっている**: `wartime_supply_inputs_covered` は、全建物が稼働率1.0で消費する Iron の1か月分(Dwarf: 790)を国家備蓄に求める。Iron が律速の国では備蓄が常に枯渇に近く(Dwarf 245)、**条件が成立しない**(§7.3)。

### 6.2 戦時MilitaryFactoryの建設(P28-002)が起きない理由(Dwarf、240か月)

| 条件 | 値 | 結果 |
|---|---|---|
| 建設キューに MilitaryFactory なし | 0件 | 成立 |
| 実月産 < 日次需要 × 30 | 379 < 480 | 成立 |
| **入力の備蓄が1か月分以上**(全建物 + 追加1 Level、稼働率1.0) | Iron 245 < 790 | **不成立** |
| 国庫 ≥ 建設費 + 経常支出 × 予備月 | 国庫 16,462 | 成立 |

MilitaryFactory のみの需要で数えても Iron 270(8 Level × 30 + 新規 30)に対し 245 で不成立(§7.3)。
