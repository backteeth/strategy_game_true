## 3. 財政モデル(実コード)

- 月次収入 = Σ(州人口 × 州LS × 税率 × 1e-4)
- 月次支出 = 建物維持費 × レベル × 稼働率 + 物流容量 × 0.05 + 行政費(人口 × 0.0008)
- 税率AI(`economy::finance::decide_ai_tax_rate_delta`)
  - 赤字なら無条件に+0.01。
  - 下げるのは、下げた税率での予測収入が支出以上のときだけ。
- 州LSの月次変化(`update_state_welfare_and_unrest`、±2で打ち切り)

  | 条件 | 変化 |
  |---|---|
  | 食料あり / なし | +0.5 / −1 |
  | 雇用率≥0.9 / <0.7 | +0.5 / −0.8 |
  | 物流比率≥0.9 / <0.5 | +0.3 / −0.5(`finance.rs:201`) |
  | 税率≤0.10 / >0.25 | +0.5 / −0.8 |
  | 破産(国庫<0) | −0.5(建物稼働×0.8も) |

- 物流比率 = 物流容量 / 物流使用量(上限1)。容量 = 基礎容量 + Railwayレベル × 50。
  - Railway: 建設費800、所要進捗60、維持費20、最大レベル5。

## 4. 仮説A〜Eの判定

均衡の境界: 行政費が支出の約95%を占めるため、赤字を解消する税率はおよそ

- t* ≈ 0.0008 / (LS × 1e-4) = 8 / LS

となる。t* ≤ 0.25 が成り立つのは LS ≥ 32 のときだけ。

| 仮説 | 判定 | 根拠 |
|---|---|---|
| A: 行政費に対する収入構造上、税だけでは均衡できない領域がある | **確定** | LS<約32でt*>0.25。いずれの事例も、税率0.25超への移行時点の加重LSは30.8〜34.1 |
| B: 税率AIの予測が誤っている | **否定**(加速要因) | 予測は正しい(t*と実税率が一致して推移)。ただし赤字時の無条件引上げが0.25を越え、崩壊を加速する |
| C: 領土(雇用の少ない大人口州)の獲得・保持 | **引き金・加速要因** | A_allのOceanicは州8(人口210万、雇用ほぼ0)を保持して崩壊した。現行ではこの州を1802年の割譲で失い、LSは91〜100になる。現行のDwarfは征服した州0・2・8・9・22が低雇用 |
| D: LS→0と破産の相互強化 | **確定**(終盤) | LSが0に近づくと収入も0に近づき、破産の−0.5と稼働×0.8が重なる |
| E: 募兵・軍事費 | **間接のみ** | 軍事費は財政に入らない。募兵は戦争の経過(領土)を変え、Cを通じて作用する |

根本原因は、低雇用州で物流比率<0.9のときにLSが単調減少する構造である(A・Cの前段)。

## 6. 候補

いずれも環境変数で有効化する一時パッチ(差分はスクラッチに保存)。

- **F1**: 赤字でも税率を0.25より上げない。
- **F1b**: F1に加え、0.25を超えていれば下げる。
- **RAIL t**: 建設AIの優先度2.5の後・3の前に置く。
  - 対象: 自国が所有・支配する州のうち、物流比率<tで、Railwayが最大レベル未満かつ建設キューにない州。
  - 物流比率が最小の州にRailwayを1件建設する。
  - 資金条件: 国庫 ≥ 建設費 + 月次支出 × 3(優先度3と同じ予備資金)。
- **G g**: RAIL 0.9に「税率≥g」の起動条件を付けたもの。

税率を低く固定する案・巨額国庫を付与する案・LSペナルティを撤廃する案は、§5の因果(LS低下が先、税率は後)に照らして根本原因に作用しないため、候補から外した。F1は「税率が主因か」を検証する対照として実施した。

### 7.3 長期均衡の根拠(国庫が正であること以外)

- 加重LSは段差状に推移する。長期間は完全に平坦で、人口増加で物流使用量が容量を超えた月に下がり、Railwayの完成後に再び平坦になる。
  - A_war世界のArcadia: 1825〜1844年はLS 39.20→39.93で平坦、1845〜1848年に35.86へ下がり、1848〜1850年は平坦。t*は0.239で0.25未満。
  - A_all世界のDwarf(2州に縮小): 1828〜1841年はLS 59.46で平坦、1842〜1847年に45.59へ下がり、1848〜1850年は平坦。
    - この低下期間は国庫が約2,500で、建設費800 + 月次支出×3の予備資金を満たせず、Railwayを着工できなかった。
- 赤字の月は、均衡税率の前後で上下する振動である。国庫は窓の中で横ばいか増加している。
- 残るリスク(Medium): 余裕が最も薄いのはLS 35.86(境界32まで約4)。予備資金を満たせない小国では、Railwayの着工が遅れて段差が大きくなる。600か月より先は未検証。

### 7.4 起動ゲート付き(G)が失敗する理由

- 税率が0.20〜0.22に達した時点では、低雇用州のLSがすでに0近くまで落ちている。
- Railwayは物流を戻すだけで、LSを上げるのは+0.3/月(雇用<0.7では純増0)にとどまる。そのため回復が間に合わない。
- 崩壊を防ぐには、LSが下がり始める前に物流を0.9以上に保つ必要がある。これは早期介入であり、既存の序盤の正規値を変える。
