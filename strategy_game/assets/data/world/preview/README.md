# ワールド設定の検証用データ(P32-005 / M1)

**これは検証用データであり、正式な州境界・国家配置・歴史設定ではありません。** 正式な全世界用のワールド設定ファイルは、まだ作成されていません。

| ファイル | 内容 |
|---|---|
| `provinces.ron` | プロヴィンス表。`coverage: Partial`(地図全体の陸セルを網羅していない)。IDは明示保存された安定値で、読み込み時に生成・変更されません。 |
| `states.ron` | ステート配置(3ステート)。**所属関係の正本**。 |
| `supply_connectivity_scenario.ron` | 補給連結性の検証用シナリオ(P32-032)。主体ごとの補給源と通行可能範囲(`passable_provinces` / `passable_states`)。**検証入力であり、正式な国境・所有・実効支配ではない**。経済シナリオとは無関係。`world_reach_check --scenario` で確認する。 |

## 対象地域
中心 `(q=83, r=81)` から距離3以内の陸ヘックス 29 個(`q=80..86`, `r=78..84`)。海岸と河川を含む(河川は地理JSON側のデータで、ステート境界とは無関係)。

- ステートに所属する陸プロヴィンス: 26(ステート 20=7, 21=13, 22=6)
- ID表にあるが未割当の陸プロヴィンス: 3(IDは 17903 / 18110 / 18501)
- ID表の対象外の陸セル(検証範囲外): 周辺の陸セル(地図上で暗く表示)
- 海・湖にはプロヴィンスもステートも割り当てていません。

ステート表示名は翻訳キー `world_preview.state.*`(`assets/localization/`)です。

## 地図更新(P32-025)との関係
地図は `hex-atlas-map_2.json`(schemaVersion 10)へ更新された(陸が718セル増え、河川が95本増えた。検証地域の29セルと、その周辺5セル以内の地形・河川は不変)。
このプロヴィンス表のIDは**振り直さず据え置いた**(ID・ステート所属・`next_province_id` は不変)。そのため、このIDは「更新後の地図を全世界で初回採番した結果」とは一致しない(一致させる必要はない)。
地図で増えた陸セルには、検証範囲外のためIDを発行していない。必要になった時は `next_province_id`(34503)以降を払い出し、既存IDを再利用しない。
`geography` の指紋は更新後の地図に合わせた(検証地域は不変)。

## 起動方法
`strategy_game/` で:

```
cargo run --release --bin hex_map_preview -- --world-preview
```

`--world-preview` なしの通常起動は従来どおり地理プレビューのみです。追加操作: `4`=ステート塗り / `B`=ステート境界の切替 / `F`=検証地域へ移動 / `Home`=全体表示。別ファイルを試す場合は `--world-provinces <path> --world-states <path>`。

読み込みにはM0のローダーとAuthoring検証を使います(Partialや未割当は許容、重複ID・不正参照・地理との不整合はエラー)。
