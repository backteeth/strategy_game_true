# ワールド設定の検証用データ(P32-005 / M1)

**これは検証用データであり、正式な州境界・国家配置・歴史設定ではありません。** 正式な全世界用のワールド設定ファイルは、まだ作成されていません。

| ファイル | 内容 |
|---|---|
| `provinces.ron` | プロヴィンス表。`coverage: Partial`(地図全体の陸セルを網羅していない)。IDは明示保存された安定値で、読み込み時に生成・変更されません。 |
| `states.ron` | ステート配置(3ステート)。**所属関係の正本**。 |
| `supply_connectivity_scenario.ron` | 補給連結性の検証用シナリオ(P32-032)。主体ごとの補給源と通行可能範囲(`passable_provinces` / `passable_states`)。**検証入力であり、正式な国境・所有・実効支配ではない**。経済シナリオとは無関係。`world_reach_check --scenario` で確認する。 |
| `division_movement_scenario.ron` / `division_movement_scenario_no_bridge.ron` | 師団の初期配置と移動の検証用シナリオ(P32-034 / M6-a)。国家ラベルと `CountryId` の対応、ステートごとの所有国、プロヴィンスごとの初期支配国の上書き、師団(ID・所属国・初期位置・速度)、基準日数。**所有・支配は検証入力であり、正式な全世界の所有・実効支配データではない**。経済シナリオ・補給検証用シナリオの通行範囲とは無関係。`no_bridge` は 17903 の上書きを外した版(差はそこだけ)。`world_move_check` で確認する。 |
| `division_battle_scenario.ron` | 交戦・進入・戦闘・退却の検証用シナリオ(P32-035 / M6-b)。M6-a の項目に加えて、**交戦する国の組 `wars`**(国家ラベル。双方向)と、師団ごとの戦闘能力 `combat`(省略した項目は標準値)を持つ。**所有・支配・交戦関係・戦闘能力は検証入力であり、正式な世界データではない**。旧 WarRegistry・経済シナリオ・補給検証用の通行範囲とは無関係。M6-c(P32-036)で、守備隊なしの到着と攻撃側の勝利は、その場で対象プロヴィンスの実効支配を変える(D8: 旧本番の即時占領。法的所有=ステートは変わらない)。場面 G(戦闘に参加しない交戦国の師団が残るため支配の更新が見送られる)を追加(師団14〜16)。`world_move_check --scenario` で確認する。 |
| `division_supply_scenario.ron` | 日次補給の検証用シナリオ(P32-037 / M6-d)。`division_battle_scenario.ron` に、**国家ごとの首都と初期の軍需物資の備蓄(`supply.countries`)**と、師団の補給消費量(`supply.divisions`。既存の需要計算の入力)を加えたもの。**検証入力であり、正式な世界データではない**。補給の設定(`supply`)がないシナリオは従来どおり動く。`world_move_check --scenario` で確認する(`--capital` で首都を変更できる)。 |
| `division_war_scenario.ron` / `division_war_elimination_scenario.ron` | 戦争の記録・終結・休戦の検証用シナリオ(P32-042 / M7-b)。`division_territory_scenario.ron`(P32-041)と同じ所有・支配・師団・補給で、交戦関係を**戦争の記録 `war_records`**(戦争 ID・両陣営の代表国と支持国・対象ステート 1 件・開始日)にしたもの。A は白紙講和・割譲・同一目標の別戦争の失効・別の戦争で続く敵対、B は国家消滅による他戦争の決着と支持国の除去。`wars` だけのシナリオは従来どおり動く(同じ組を記録と `wars` の両方に書くことはできない)。**検証入力であり、正式な世界データではない**。`world_move_check --end-war`・`--wars` で確認する。 |

## 対象地域
中心 `(q=83, r=81)` から距離3以内の陸ヘックス 29 個(`q=80..86`, `r=78..84`)。海岸と河川を含む(河川は地理JSON側のデータで、ステート境界とは無関係)。

- ステートに所属する陸プロヴィンス: 26(ステート 20=7, 21=13, 22=6)
- ID表にあるが未割当の陸プロヴィンス: 3(IDは 17903 / 18110 / 18501)
- ID表の対象外の陸セル(検証範囲外): 周辺の陸セル(地図上で暗く表示)
- 海・湖にはプロヴィンスもステートも割り当てていません。

ステート表示名は翻訳キー `world_preview.state.*`(`assets/localization/`)です。

## 地図更新(P32-025)との関係
地図は `hex-atlas-map_2.json`(schemaVersion 10)へ更新された(陸が718セル増え、河川が95本増えた。検証地域の29セルと、その周辺5セル以内の地形・河川は不変)。
このプロヴィンス表のIDは**振り直さず据え置いた**(ID・ステート所属・`next_province_id` は不変)。そのため、このIDは「更新後の地図を全世界で初回採番した結果」とは一致しない(一致させる必要はない)。
地図で増えた陸セルには、検証範囲外のためIDを発行していない。必要になった時は `next_province_id`(34503)以降を払い出し、既存IDを再利用しない。
`geography` の指紋は更新後の地図に合わせた(検証地域は不変)。

## 起動方法
`strategy_game/` で:

```
cargo run --release --bin hex_map_preview -- --world-preview
```

`--world-preview` なしの通常起動は従来どおり地理プレビューのみです。追加操作: `4`=ステート塗り / `B`=ステート境界の切替 / `F`=検証地域へ移動 / `Home`=全体表示。別ファイルを試す場合は `--world-provinces <path> --world-states <path>`。

読み込みにはM0のローダーとAuthoring検証を使います(Partialや未割当は許容、重複ID・不正参照・地理との不整合はエラー)。
